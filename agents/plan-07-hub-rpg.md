# Plan 서브에이전트 지침 — 기획서 4판: "느티나무 마을"에서 출전하는 역사 RPG

## 맡은 일

사용자가 게임의 짜임을 크게 바꾸기로 했다. 지금의 `spec.md`(3판, 사용자 승인 2026-10-08)를 **4판**으로 다시 쓴다. 4판은 사용자 승인을 받은 뒤 구현의 기준이 된다.

- 지금의 `spec.md`를 고치기 전에 그대로 `docs/spec-3판.md`로 복사해 남긴다(첫 줄에 "4판으로 바뀌기 전의 기획서, 2026-10-30에 옮김" 한 줄).
- 4판은 3판에서 **그대로 맞는 것은 살리고**(기술과 저장, 홈 화면과 배포, 그림의 기준, 고증의 원칙과 근거 목록, 실제 인물과 전쟁의 수위, ①의 내용과 대본, 15절의 의견), **바뀐 것은 고쳐 쓴다**. 3판의 결정을 뒤집는 곳은 13절에 "무엇이 무엇으로 바뀌었는지"를 남긴다.

## 사용자가 정한 것 (2026-10-30)

조정자(메인 Claude)가 두 번에 걸쳐 게임성을 분석하고 방안을 냈고, 사용자가 아래와 같이 정했다.

**앞선 분석의 요지**(조정자): 지금 게임은 "고르며 읽는 역사 그림책"에 가깝다. 한 해 31분 가운데 글을 읽는 시간이 약 27분이고, 성장·위험·보상이 거의 없다(3판 5.3의 "넣지 않는 것" — 레벨 올리기, 싸움, 점수, 옷 갈아입히기 — 과 "실패라 하지 않는다" 때문). 그래서 RPG의 재미 엔진을 **역사가 곧 규칙이 되는 모양**으로 다시 넣기로 했다.

**사용자의 결정**:

1. **짜임**: 거점 마을 + 에피소드 출전 + 레벨·싸움·점수의 구조로 설계한다.
   - 거점은 **시간 밖의 마을 "느티나무 마을"**(오백 년을 산 느티나무의 정령이 사는 곳 — 일곱 이야기를 잇는 동료이기도 하다). 거점이 시간 밖이라 상점·꾸미기가 고증에 걸리지 않는다.
   - **시설**(사용자: "지금대로 좋다"): 시간의 문(느티나무 — 연표 위의 에피소드를 골라 출전, 선생님 암호로 진도에 맞춰 열기), 알림판(의뢰·새 에피소드·이번 주 과제·선생님 공지), 도구점(호미·낫·도리깨·베틀·붓 — 도구가 놀이와 현장의 능력을 바꿈), 공방(무기 상점 대신 — 에피소드에서 얻은 재료로 측우기·앙부일구·신기전·화차·거북선 모형 등 발명품을 만들어 장비로), 포목점·댕기방(옷과 머리 꾸미기 — 시대·신분별 차림을 배움, 거점에서는 자유·현장에서는 역할의 차림), 장터(얻은 것을 팔고 사기 — 받는 돈이 시대에 따라 바뀜: 쌀·베 → 상평통보), 박물관(유물 기증·인물 카드·시대별 전시), 우리 집(꾸미기·남길 것·칭호), **서당**(아래), 주막(소문 — 힌트와 다음 에피소드 맛보기), 사진관(기념사진을 이미지로 저장). **방명록은 넣지 않는다.**
   - **에피소드**: 일곱 이야기를 10~15분짜리 에피소드 4~6개씩으로 나눈다(한 차시에 한두 개). 한 에피소드는 의뢰 목표 → 현장 맵(탐험·대화·작은 고비 둘셋) → 큰 고비(보스) → 결과(별·점수·경험치·엽전·유물). 다시 해서 별을 더 받을 수 있다. ①은 이미 만든 내용(봄~겨울의 미션, 놀이 다섯, 맵, 대화 장면 그림 마흔한 장)을 에피소드로 다시 자른다(조정자의 초안: 새 도읍의 봄 / 단오와 김매기 / 장정들이 떠난 가을(큰물) / 나라 몫과 소금 고개 / 제삿날과 겨울 글공부 / 새 궁궐 경복궁(정점)).
   - **레벨과 성장**: 경험치(고비를 넘김·탐험·도감·서당), 레벨 1~30과 능력치(힘·지혜·솜씨·인심), 솜씨 나무(농사 → 과학 → 수군 → 상업 — 에피소드를 깨면 시대 순으로 열림. 볍씨를 바로 뿌리던 것이 모내기로 "업그레이드"되듯 시대의 발달이 곧 성장), 장비와 칭호, 에피소드의 권장 레벨. 되풀이 노가다를 막는 장치.
   - **점수**: 에피소드마다 별 셋(고비를 넘김 / 덜 잃음 / 배운 것을 씀)과 점수, 내 최고 기록. **순위는 넣지 않는다.**
   - **서당 — 학습 퀴즈 코너**(사용자가 더함): 퀴즈를 풀어 점수·경험치(와 엽전)를 얻는다.
     - 학생이 **학년·과목·주제를 고르면 그 주제의 문제 20개**를 푼다(모든 과목에서 아무 문제나 뽑는 것이 아니다). 같은 주제를 다시 해도 같은 문제만 나오지 않게, **주제마다 문제를 20개보다 훨씬 많이** 만들어 두고 이 기기에서 아직 풀지 않은 것부터 낸다.
     - 기본 문제는 **5학년 사회의 역사 단원 전체**(선사 시대부터 대한민국의 독립까지 — 정확한 끝은 2022 개정 교육과정과 교과서에서 확인한다).
     - **관리자(또는 교사)가 문제를 더할 수 있다.**
     - **게임을 완성한 뒤**, Claude가 **5·6학년 국어·영어·수학·과학·사회 다섯 과목의 문제 은행**을 미리 만들어 두고 학생이 그것으로 퀴즈를 푼다.
2. **싸움**: 카드 겨루기와 문제를 맞혀 공격하기를 섞는다. 조정자가 아래의 안을 냈다 — **사용자가 아직 답하지 않았으니 권장안으로 쓰고 13.2에 "확인 필요"로 둔다.**
   - 상대는 사람이 아니라 **고비**(큰물·가뭄·추위·거센 물살·줄어드는 군량 등)와 **옛이야기 속 존재**. 실제 나라·사람을 적으로 삼지 않는다. 피·죽음은 보이지 않는다(3판 7.3 그대로).
   - **카드로 고르고, 문제로 힘을 싣는다**: 차례마다 솜씨 카드 하나를 고른다(고비와의 상성 — 큰물에는 "물꼬 트기"가 세다). 그 카드의 지식에 닿는 문제 하나가 뜨고, 맞히면 카드의 힘이 커지고(두 배, 덧효과), 틀려도 기본 힘은 나가며 풀이 한 줄이 뜨고 그 문제는 그 겨루기 안에서 다시 나온다.
   - **카드는 배워서 얻는다**: 에피소드의 일과 서당의 주제를 마치면 카드를 얻거나 키운다. 출전 전에 여덟 장쯤 골라 간다.
   - **기세**: 잇달아 맞히면 기세가 차고, 차면 동료(느티나무 정령)·이웃과의 합동 기술.
   - **큰 고비**: 단계 사이에 그 에피소드의 핵심을 묻는 "지혜 겨루기" 세 문제(예: 궁궐 왼쪽에 종묘, 오른쪽에 사직)를 맞힐수록 고비의 방패가 깎인다.
   - 문제의 꼴: 고르기, OX, 순서 맞추기(연표), 짝 맞추기(인물–한 일), 지도에서 찍기. **시간 제한은 두지 않는다.** 기력이 0이 되어도 이웃·동료가 구해 주고 별만 준다.
   - 서당에서는 "도깨비와 내기" 같은 겨루기 꼴로 고른 주제의 문제를 풀 수도 있게 한다(서당 퀴즈 20문제와 따로 — 어떻게 나눌지 4판에서 정한다).
3. **옛이야기 속 존재를 넣는다**(도깨비 — 씨름 겨루기·수수께끼 내기, 불가사리 — 쇠를 먹는 전설 속 짐승 등). 사실과 섞이지 않게 "옛이야기"라고 표시한다.
4. **방명록과 순위는 하지 않는다.** 문제 은행과 교사가 입력하는 문제를 위해 **교사용 서버가 필요하면 제안하라**고 했다. 조정자가 아래 두 안을 냈다 — **사용자가 아직 고르지 않았으니 4판에 두 안을 견주어 쓰고 13.2에 "결정 필요"로 둔다.**
   - **A안 — 서버 없이**: 문제 은행은 게임 파일 안의 정적 자료(과목·주제별로 나눈 JSON — 고른 주제만 받는다). 교사·관리자의 문제는 저장소의 파일(또는 관리자가 쓰는 표)로 받아 새 판을 올릴 때 들어간다. 비용 0, 개인정보 걱정 없음. 교사가 스스로 웹에서 바로 넣을 수는 없다.
   - **B안 — 같은 Vercel 프로젝트에 작은 교사용 서버**: Vercel 함수 + Vercel에 붙여 쓰는 무료 DB. 교사 쪽 화면(`/teacher`)에서 교사만 로그인 → 반 만들기 → 반 코드(6자리) → 문제를 넣거나 표(CSV)로 올림 → 학생은 서당에서 반 코드를 한 번 넣으면 "선생님 문제" 주제가 생긴다. **학생 정보와 학생의 기록은 서버에 가지 않는다**(학생은 읽기만, 기록은 지금처럼 기기에). 교사 계정을 만들고 DB를 붙이는 일은 사용자가 직접 해야 한다. 새 패키지가 하나쯤 필요할 수 있다(승인 필요). 운영할 곳이 하나 는다.
   - 조정자의 권장: **첫 조각은 A안으로**, 문제의 꼴은 B안으로 그대로 옮길 수 있게 정해 둔다. 교사가 직접 넣는 것이 필요해지면(다른 교사도 쓰게 되면) B안을 더한다. 4판은 이 권장을 쓰되 두 안의 차이(무엇을 할 수 있나, 사용자가 할 일, 개인정보, 비용, 운영)를 사용자가 고를 수 있게 적는다. 만 14세 미만 학생의 개인정보를 받지 않는 것을 원칙으로 둔다.
5. 시설 목록은 위와 같다.

**뒤이은 결정(같은 날, 조정자가 SendMessage로 알림)**: 사용자의 말 "권장대로 하는데 서버는 b안으로 할게". → 2번 싸움은 권장안 그대로 확정. 4번 교사용 서버는 **B안으로 확정**(3판의 "서버 없음"이 바뀜). 4판에 B안을 자세히 쓴다: 쓸 서비스와 무료 범위(쉬면 멈추는지, 방학 동안), 필요한 새 패키지(승인 목록), 관리자(모든 반의 기본 은행)·교사(제 반)·학생(로그인 없이 반 코드로 읽기만)의 권한, 교사 로그인 방식, 자료의 꼴, 개인정보(학생 정보는 서버에 가지 않음), 보안(비밀 값은 Vercel 환경 변수), 사용자가 직접 할 일의 차례, 기본 은행을 정적 자료로 둘지 DB에 둘지, 넣는 바퀴(첫 조각 바로 다음을 권장으로 하되 첫 조각이 더 싸면 그렇게). 문제의 꼴은 처음부터 B안에 맞춘다.

## 4판에 꼭 들어갈 것

1. **한눈에 보기** — 새 짜임을 5학년 교사가 1분 안에 알 수 있게. 거점 → 출전 → 귀환의 한 바퀴를 ①의 예로.
2. **세계와 동료** — 느티나무 마을(시간 밖), 시간의 문과 연표, 느티나무 정령(이름·성격·말투·하는 일: 낯선 말 풀이, 길 알려 주기, 시대 견주기, 끝에 한 가지 묻기). 동료의 그림은 캔바로(승인된 시안의 화풍).
3. **시설마다**: 하는 일, 화면, 배우는 것, 첫 조각에 넣을지. 꾸미기는 도트 인물에 옷·머리를 겹쳐 그리는 방식(코드로 그리는 도트 그림이므로), 대화 장면에는 주인공이 서지 않으므로 꾸미기가 보이는 곳은 맵이다 — 사실과 다르면 바로잡는다. 장터의 화폐가 시대에 따라 바뀌는 규칙.
4. **에피소드** — 일곱 이야기의 에피소드 나누기(①은 자세히, ②~⑦은 초안), 한 에피소드의 흐름과 시간, 별·점수의 기준, 다시 하기, 선생님 암호로 열기(서버 없이 되는 방법), 3판의 역할(현장 역할 포함)을 에피소드에서 어떻게 고르는지. **3판의 계절·해 ☀·살림/기력/인심·한 해 이름·한 해 돌아보기·남길 것·이야기 잇기를 무엇으로 바꾸고 무엇을 살리는지.**
5. **고비 겨루기** — 위 2번의 권장안을 규칙으로: 기력·카드·상성·문제·기세·큰 고비의 단계, 이야기마다의 고비와 상성 표(배우는 것과 잇는다), 옛이야기 속 존재의 목록과 쓰는 곳, 7.3의 수위. 문제의 출처(그 에피소드의 내용, 앞 에피소드, 서당 주제).
6. **레벨·능력치·솜씨 나무·장비·칭호·엽전** — 숫자의 초안(경험치 곡선, 한 에피소드에서 얻는 양, 레벨 30까지 걸리는 판 수가 일곱 이야기의 판 수와 맞게), 되풀이로 불리지 못하게 하는 장치(같은 날 같은 주제의 서당 경험치는 줄어든다 등), 엽전과 경험치는 **배우는 행동에서만** 나온다는 원칙.
7. **서당 퀴즈** — 학년·과목·주제 고르기 → 20문제의 흐름, 문제마다 풀이, 틀린 문제 다시 보기(오답 노트), 이 기기에서 푼 문제를 기억해 안 푼 것부터 내는 규칙, 점수와 경험치, 문제의 꼴(위 다섯 가지 + 과목에 따라 더할 꼴).
8. **문제 은행** — 
   - 자료의 꼴(id, 학년, 과목, 주제, 성취기준 코드, 꼴, 물음, 고를 것, 답, 풀이, 어려움, 근거, 판), 주제의 단위(2022 개정 교육과정 **성취기준**을 뼈대로 — 5·6학년 사회·수학·과학·영어는 검정 교과서라 출판사마다 단원이 다르다. 국어는 국정. 사실이 아니면 바로잡는다), 주제당 문제 수(20문제를 세 번은 겹치지 않게 — 60개 이상, 역사는 더), 전체 규모의 어림.
   - **첫 은행**: 5학년 사회 역사 단원 전체의 주제 목록(성취기준과 사용자의 교과서 — 아이스크림 — 단원에 맞춰)과 주제마다의 문제 수.

   - 그림이 필요한 문제(수학 도형·그래프, 과학 그림, 지도)와 소리가 필요한 문제(영어 듣기)를 어떻게 할지(코드로 그리는 SVG, 브라우저의 소리 읽기 기능 등 — 새 패키지 없이 되는지).
9. **교사용 서버** — 위 4번의 A·B안 견주기와 권장, 고르면 생기는 일.

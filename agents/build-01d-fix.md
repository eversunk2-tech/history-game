# Build 서브에이전트 지침 — 태블릿 바퀴 고치기 (Review 반영)

## 맡은 일

Review가 태블릿 바퀴를 **"고친 뒤 통과"**로 판정했다(막음 0, 고쳐야 함 1, 권고 5). 프로젝트 루트의 `review.md`를 읽고 아래를 고친다. 번호는 `review.md`의 번호다.

## 수정 범위

- 앞 지침(`agents/build-01d-tablet.md`)과 같다. `spec.md`, `CLAUDE.md`, `agents/**`, `review.md`, `docs/reviews/**`, 대본, 그림 폴더는 고치지 않는다.
- 서비스 워커, 새 패키지, 저장의 꼴 바꾸기, git 커밋·푸시는 안 된다. 5173 서버는 끄지 않는다. 사파리를 띄우려 하지 않는다.
- 아래에 없는 것은 고치지 않는다.

## 고칠 것

### 꼭 고칠 것

- **1번 — 큰 갤럭시탭의 크롬을 컴퓨터로 잘못 가리는 것.** 크롬은 화면이 크고 메모리가 넉넉한 안드로이드 태블릿에서 "데스크톱 사이트"를 기본으로 켜고, 그때 사용자 에이전트가 리눅스 PC처럼 보인다. 그런 기기에서도:
  - 탭으로 열면 안내가 저절로 뜨고, "처음부터"를 누르면 "이 창에서 시작할까요?"를 묻고, 세로로 들면 "가로로 돌려 주세요"가 뜬다.
  - 안내에는 갤럭시탭의 순서만 나온다. 설치 물음이 와 있으면 가린 갈래와 상관없이 단추 하나를 보인다.
  - 가리는 방법: 리눅스라고 말하면서 손가락 점이 여럿이면 갤럭시탭으로 본다(아이패드를 맥으로 말할 때 가리는 것과 같은 방식). 터치가 되는 리눅스·윈도 노트북을 태블릿으로 잘못 가리는 일은 되도록 줄이되, 잘못 가려도 해가 작게 한다(안내를 닫을 수 있고, 세로 안내는 가로 창에서는 안 뜬다).
  - 시험을 더한다(가린 갈래별로).

### 함께 고칠 것 (권고)

- **2번**: 설치 물음에 "설치"라고 답한 뒤 추가가 끝날 때까지 안내가 "손으로 하는 세 걸음"으로 바뀌어 보이는 것, 안내를 읽는 도중에 설치 물음이 오면 세 걸음이 단추 하나로 갑자기 바뀌는 것. 답한 뒤에는 "홈 화면에 추가하는 중이에요" 같은 한 줄로, 읽는 도중에는 모양을 갈아 끼우지 않게.
- **3번**: 안내 문구 셋. "이제 이 창을 닫고"의 "이 창"이 무엇인지 헷갈리지 않게("이 크롬 창" 등), 단추 하나짜리 안내에서는 추가하기 전에 "이제…"가 나오지 않게, "손으로 하는 법 보기"를 자연스러운 말로. 5학년이 읽는 글이다.
- **4번**: 세로 안내가 떠 있는 동안 자판이 밑으로 통해 주인공이 걷는 것.
- **5번**: 덤을 바로 누르고 금방 대화를 마치면 해 ☀ 풀이 알림이 낡은 채 잠깐 뜨는 것.
- **6번**: 시험의 구멍(한 일을 적지 않게 하거나 계절을 가리지 않게 망가뜨리면 시험이 실패하지 않고 끝나지 않는 것, 코드 파일 이름을 찾는 식을 느슨하게 해도 못 잡는 것).

## 확인할 것

- `npm run typecheck`, `npm run build`, `npm test`.
- 빌드본을 크롬으로: 큰 갤럭시탭(리눅스라고 말하고 손가락 점이 여럿)으로 꾸며 안내·물음·세로 안내가 뜨는지, 작은 갤럭시탭·아이패드·PC·홈 화면에서 연 것은 앞과 같은지, 설치 물음을 꾸며 2번을, 세로에서 자판을 눌러 4번을 본다. 봄을 한 번 끝까지.
- 확인하지 않은 것을 확인했다고 쓰지 않는다. 직접 띄운 서버와 브라우저는 끝나면 멈춘다.

## 끝나면 보고할 것

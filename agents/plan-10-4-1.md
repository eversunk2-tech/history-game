## 맡은 일

초등 5학년 역사 게임 「조선에서 한 해 살기」의 4판 첫 바퀴 **4-1**을 어떻게 만들지 계획한다.
- 4판 기획서(`spec.md`)는 사용자가 승인했다(2026-10-30). 4-1의 범위는 11절 표의 "4-1 첫 조각" 줄이다.

- 너는 계획까지만 만든다. 구현은 사용자 승인 뒤 다른 Build가 한다.

CLAUDE.md의 Plan 단계: "어떤 앱을 만들지, 파일 구조는 어떻게 할지 정리한다. 작성한 계획은 spec.md로 저장하며, 사용자 승인을 받는다."

## 네가 답할 것(근거를 들어)

가. **무엇을 만드나(화면과 흐름)**
   - 4-1에서 아이가 처음 켜서 ①-1을 끝내고 거점으로 돌아와 서당을 하기까지를 화면 차례로 적는다. 제목 → 소개 → 거점 → 출전 준비 → 현장(봄) → 작은 고비 → 큰 고비 → 결과 → 성장 → 서당 같은 식이다.
   - 3판의 화면 가운데 그대로 쓰는 것, 고쳐 쓰는 것, 버리는 것을 가른다(10.5·10.6 기준).
   - 지금 한 해(여름·가을·겨울)는 어떻게 되나? 4-3에서 ①-2~①-6이 된다. 4-1 동안 그 코드와 대본을 어디에 두는지, 쓰지 않는 길을 어떻게 막는지 정한다.

나. **파일 구조**
   - 새로 생기는 폴더와 파일을 적는다. 예: 겨루기 엔진, 거점 맵, 출전 준비, 결과, 성장, 서당, 문제 은행 자료, 저장 꼴 5.
   - 고치는 파일, 지우는 파일, 각 파일이 맡는 일, 크기 어림을 적는다.
   - 규칙: 빌드 결과는 JS 파일 하나, 새 패키지 없음, 서비스 워커 없음, 코드 파일을 늦게 불러오는 조각으로 쪼개지 않음.
   - 겨루기 엔진은 화면과 떼어 순수한 셈으로 둔다. 같은 씨앗이면 같은 결과가 나와야 하고, 11절 "막다른 판 없음"의 시험을 엔진만으로 돌린다.

다. **자료의 꼴**
   - 10.2와 9.3을 4-1에서 실제로 쓸 TypeScript 꼴로 구체화한다.
     - 에피소드, 고비, 카드, 장비, 시대 잠김, 문제(`Question`), 서당 기록, 성장(레벨·경험치·능력치·돈), 꾸미기, 저장 꼴 5.

   - 9.3이 4판 고침 2(교사 인증 코드, 학생 로그인 없음)와 어긋나는 데가 있으면 적고, 4-1에서 어떻게 할지 권한다. 10.3 자체는 고치지 않는다.

라. **글과 문제를 만드는 길**

## 맡은 일

Review가 바퀴 1-가를 "고친 뒤 통과"로 판정했다. 프로젝트 루트의 `review.md`를 읽고, 아래에 적은 항목만 고친다.
`review.md`의 번호를 그대로 쓴다.

## 수정 범위

- 앞 지침(`agents/build-01a-framework.md`)과 같다: `src/**`, `tests/**`와 프로젝트 설정 파일. `spec.md`, `CLAUDE.md`, `agents/**`, `review.md`, `docs/**`는 고치지 않는다.
- 패키지를 더 설치하지 않는다. git 커밋·푸시를 하지 않는다.
- **아래에 없는 것은 고치지 않는다.** `review.md`의 "1-나로 넘김"(14~22번)과 여기 적지 않은 권고(7·8·11·13번)는 손대지 않는다. 견본 장면의 글과 수치도 아래에서 말한 것 말고는 그대로 둔다(1-나에서 대본을 쓰며 다시 쓴다).

## 고칠 것

### 꼭 고칠 것

- **1번 — 화면 높이가 낮을 때 글자와 단추가 줄어드는 것.** 바탕 글자에 바닥을 두어, 주소 줄 때문에 높이가 줄어든 화면(1024×690쯤, 1366×650쯤)에서도 본문 20px 이상, 선택지 단추 56px 이상이 지켜지게 한다. 줄어든 높이는 그림 칸과 빈 곳이 받게 한다. 고친 뒤 **1024×690에서 글자 수 예산을 꽉 채운 장면**(지문 100자, 선택지 26자 셋, 둘 잠김과 까닭 30자, 결과 90자, 수치 변화 셋, 카드 둘, 쪽지 50자)이 넘치지 않는지 직접 잰다. 들어가지 않으면 글 칸 안에서 세로로 넘길 수 있게 하는 등 글이 잘리지 않는 길을 택하고, 무엇을 택했는지 보고한다. 1024×768, 1180×820, 1920×1080에서 달라진 것이 없는지도 본다.
- **2번 — 바람을 가릴 줄(`wishOutcomes`)이 빈 집이 "할 수 있는 집"이 되어 한 해 끝에서 빈 화면으로 멈추는 것.** 그런 집은 "준비 중"으로 남게 하고, 한 해 돌아보기를 만드는 데 실패해도 빈 화면이 되지 않게 한다(상태를 바꾸기 전에 돌아보기를 먼저 만들거나, 실패를 알리고 처음으로 갈 수 있는 화면을 둔다). 엔진이 던져서 화면이 비는 다른 길이 있는지도 살핀다. 이 잘못을 다시 만들면 잡아내는 시험을 더한다.

### 함께 고칠 것 (권고 가운데 틀에 속하고 값이 싼 것)

- **3번** — 쓰이지 않는 코드를 지운다(`lockReason`, `isOver`, `game.ts`의 `meets` 다시 내보내기, `knownPerson`, `SeasonBand`의 `done`, 화면에 쓰이지 않는 `reign`). **표시(flag) 다섯 개는 지우지 않는다**(1-나에서 쓴다). 검사기에 "남기기만 하고 아무 조건도 읽지 않는 표시"를 알림(잘못이 아니라 알림)으로 더한다.
- **4번** — 날씨 이름. 화면에 보이는 "풍년"을 날씨를 가리키는 말로 바꾼다: 가뭄 든 해 / 여느 해 / 비와 볕이 고른 해(더 짧고 쉬운 말이 있으면 그것으로 하고 보고에 적는다). 위쪽 띠와 한 해 돌아보기의 표시도 어색하지 않게 한다. 안쪽 열쇠 이름은 그대로 두어도 된다.
- **5번** — 결과 화면의 "내가 고른 일"과 고른 선택지 글을 20px 이상으로.
- **6번** — 시험의 빈틈. ㉠ 네 역할의 시작 수치가 spec 7절 표(양반 집 아들 7/6/6, 양반 집 딸 7/6/6, 농민 집 아이 4/6/5, 노비 집 아이 2/6/4)와 같은지 보는 시험을 더한다. ㉡ 검사기에 "지문·결과·쪽지에 나온 숫자(연도 포함)가 그 장면이 가리키는 근거의 글에 없다"를 알림으로 더한다.
- **9번** — 지나간 계절의 "✓"를 맞음 표시로 읽히지 않는 다른 표시로 바꾼다.
- **10번** — ① 카드의 한 줄 소개에 "유교를 내세워"를 살린다(44자 안).
- **12번** — 검사기에 "갈린 결과가 바탕 결과의 카드·표시를 빠뜨렸다"를 알림으로 더한다.

## 스스로 확인할 것

- `npm run typecheck`, `npm run build`, `npm test`가 모두 통과한다. 새 알림 때문에 지금 자료가 "잘못"으로 떨어지지 않는지 본다(알림은 시험을 깨지 않는다).
- 브라우저에서 1024×768과 1024×690으로 한 판을 끝까지 하고, 위 1번의 꽉 채운 장면을 잰다. 2번은 장면만 있고 바람 줄이 없는 집을 임시로 만들어 확인하되, **확인이 끝나면 임시로 더한 것을 프로젝트에서 모두 지운다.**
- 개발 서버는 끝나면 멈춘다.

## 끝나면 보고할 것

- 항목 번호마다 무엇을 어떻게 고쳤는지(파일)
- 세 명령의 실제 결과(시험 수), 1024×690에서 잰 글자·단추 크기와 꽉 채운 장면의 결과
- 새 알림이 지금 자료에서 무엇을 알리는지
- 고치지 못한 것, 고치다가 생긴 다른 변화, 미심쩍은 것

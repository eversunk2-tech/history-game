# Build 서브에이전트 지침 — 바퀴 1-다 고치기 (Review 반영)

## 맡은 일

Review가 바퀴 1-다를 **"고친 뒤 통과"**로 판정했다(막음 0, 고쳐야 함 3, 권고 19). 프로젝트 루트의 `review.md`를 읽고(3절 발견 사항, 4절 해 본 느낌, 5절 글과 고증) 아래에 적은 것을 고친다. 번호는 `review.md`의 번호다.

Review가 해 본 느낌: 대화 장면과 짜임은 잘 나왔다. **재미는 약한 편이다** — 봄 한 판에서 내가 정하는 것이 셋뿐이고, 덤 넷이 모두 듣기만 하는 일이며, 쪽지에는 "우물가 — 들러 볼 수 있어요"뿐이라 가 보고 싶게 만드는 한마디가 없고, 뿌린 볍씨가 잘 보이지 않는다. 사용자는 이 조각으로 짜임·재미·길이를 처음 판단한다. 이번 고치기는 작은 잘못을 바로잡는 것과 함께, **손이 적게 드는 범위에서 덤과 놀이를 조금 더 해 보고 싶게** 만드는 데 무게를 둔다.

## 고칠 것

### 가. 꼭 고칠 것

- **1번**: 계절 닫기 화면이 풀리지 않은 덤 미션을 다 한 것처럼 적는 것. 풀린 미션만 "해낸 일"로 적고, 풀리지 않은 덤 미션은 어디까지 했는지(예: 이야기 셋 가운데 하나를 들었다)로 적는다.
- **2번**: 꼭 할 일을 다 푼 뒤 무엇을 할지 알려 주는 것이 넓은 화면(띠가 한 줄인 1280×800, 1366×650, 1920×1080)에 없는 것. 어느 화면 크기에서도 "꼭 할 일을 다 했어요. 덤을 더 하거나 봄을 보낼 수 있어요"가 눈에 띄게 한다.

### 나. 해 보고 싶게 만드는 것 (10·11번과 4절)

- **덤의 한마디(11번)**: 할 일 쪽지의 덤 줄이 자리 이름만이 아니라 가 보고 싶게 만드는 한마디를 갖게 한다(예: "우물가 — 아주머니가 한양 이야기를 한다더라", "뒷산 — 동무가 나무하러 가자고 한다"). 답을 미리 말하지 않는 한 줄, 글의 한도 안에서. 맵의 말풍선에 다가갔을 때도 같은 한마디가 보이면 좋다.
- **덤에서도 조금은 정하게(11번)**: 덤 넷 가운데 적어도 둘에 작은 선택을 둔다(둘 가운데 하나 고르기, 변화는 -1~+1 — spec 5.2의 1번). 예: 우물가에서 물 긷는 것을 거들며 듣기 / 이야기만 듣기, 뒷산에서 나무를 넉넉히 하기 / 한 짐만 하고 쉬기. 어느 쪽도 "정답"이 아니어야 하고, 새 역사 사실을 지어내지 않는다(근거 목록 안에서). 대본에 함께 적는다. 덤 미션 「새 나라 이야기 모으기」의 봄 몫이 풀리는 길은 그대로 둔다.
- **볍씨가 보이게(10번)**: 뿌린 볍씨가 논 바탕에 묻히지 않게 한다(알갱이의 크기와 빛, 뿌려진 자리의 물결이나 자국, 논 바탕의 얼룩 줄이기). "고루 뿌려졌는지"를 눈으로 알 수 있어야 한다. 다 뿌린 뒤 무엇을 누를지 알기 쉽게 한다(남은 볍씨가 없으면 "다 뿌렸어요"가 도드라지게). 점수처럼 보이는 표시(백분율, 별)는 넣지 않는다.
- 처음 맵에 들어섰을 때 쪽지·화살표·알림이 한꺼번에 뜨는 것을 차례로 나누고, 해 ☀가 무엇인지 처음 덤에 다가갈 때 한 줄로 알려 준다(4절).

### 다. 권고 가운데 이번에 고칠 것

- **4번**: 미션을 푸는 일의 결과를 보다가 닫으면 이어 할 때 "미션이 풀림" 종이가 다시 뜨지 않는 것.
- **5번**: 망가진 저장의 세 가지("이어 하기"를 눌러도 반응이 없음 등). 어떤 저장이 와도 화면이 멈추지 않게 한다.
- **6번**: 1024×690과 1366×650에서 덤을 편 쪽지의 끝이 화면 밖으로 나가는 것.
- **7번**: 문장인데 18px인 글 둘.
- **8번**: 같은 배움 쪽지가 쪽지 → 카드 → 종이로 잇달아 세 번 뜨는 것. 같은 말은 한 번만 읽게 한다(카드 글과 종이의 글을 달리하거나 차례를 합친다).
- **9번**: "수첩에 적혔어요."(수첩은 아직 없다) → 지금 있는 것(봇짐, 지난 이야기)을 가리키는 말로.
- **12번**: 글의 앞뒤(해 ☀는 그대로인데 "해가 기울 때까지"·"저녁에", "떠나는 뒷모습" 뒤에도 절에서 짐을 싸는 스님, "절 마당이 어수선하다"인데 그림은 텅 빈 마당, 할머니의 "내가 네 나이 적에는 나라 이름이 고려였단다" — 주인공도 열두 살까지는 고려에서 살았다). 대본도 함께 고친다.
- **13번**: 5학년이 모를 말(김매기, 양식, 돈 구실, 곳간, "이번 철", 소개 화면 식구 줄의 "첫째" 등)을 쉬운 말로 바꾸거나 그 자리에서 풀이한다.
- **14번**: 주소에 `?seed=`를 붙이고 새 판을 열면 앞 판의 자리에서 시작하는 것.
- **15번**: 막힌 길의 까닭이 사라진 뒤 자판으로 다시 밀면 안 뜨는 것.
- **16번**: 대화 장면에서 위쪽 띠가 무대를 많이 차지하는 것(1024~1180 너비에서 두 줄 122~130px). **대화 장면과 일 놀이가 떠 있는 동안에는 띠를 한 줄로 줄인다**(계절과 수치만 남기고, 그때 쓸 수 없는 단추들은 감춘다). 승인된 시안의 느낌(무대가 화면을 가득 채움)에 가까워지게 한다. 맵 화면의 띠는 그대로 둔다.
- **18번**: 잠긴 선택지의 까닭 줄이 붙으면 낮은 화면에서 선택지가 사람의 얼굴을 가리는 것. 선택지가 뜰 때 사람을 옆으로 비키게 하거나 선택지의 자리를 얼굴 아래로 잡는다(시안의 둘째 화면처럼 사람이 한쪽으로 비켜서는 길도 있다). 사람이 둘이고 선택지가 셋일 때도 본다.
- **19번**: 맵의 작은 것들.
- **20번**: 시험의 구멍 가운데 spec 6.3의 숫자들(양식 잠김 "살림 2 이하", 나중 결과 -3·+1·-1), 나중 결과의 계절, 궂은 해의 이름을 시험으로 묶는다.

## 일하는 방법

- 차례는 가 → 나 → 다. 한 번에 다 못 하면 이 차례를 지키고 못 한 것을 보고에 적는다.
- 고친 화면은 브라우저에서 실제 크기로 찍어 본다(`docs/shots/1c-2/`). 대화 장면은 승인된 시안과 나란히 놓고 본다.
- 글을 고치면 대본(`docs/script-1395.md`)도 같이 고치고, 검사기의 글 한도를 넘지 않는지 본다.
- 저장의 꼴을 바꾸면 `SCHEMA`를 올리고 옮기는 함수를 더한다. 옛 견본은 지우지 않는다. 꼴을 바꾸지 않고 고칠 수 있으면 그쪽이 낫다.

## 스스로 확인할 것

- `npm run typecheck`, `npm run build`, `npm test` 통과.
- 브라우저에서 1024×768, 1024×690, 1366×650, 1920×1080으로 봄을 끝까지: 꼭 할 일을 다 푼 뒤의 안내, 계절 닫기의 글, 덤의 한마디와 선택, 볍씨, 대화 장면의 띠와 선택지 자리, 결과를 보다가 새로 고쳤을 때의 종이, 망가진 저장 세 가지.
- 봄 한 판의 글자 수가 얼마나 늘었는지(덤에 선택이 생겼으므로) 센다.
- 확인하지 않은 것을 확인했다고 쓰지 않는다. 직접 띄운 서버와 브라우저는 끝나면 멈춘다.

# 시안 C 「두루마리 장면」 — 헤리티지 + 이머시브

먼저 `agents/mockup-ui-common.md`(세 시안이 함께 지킬 것)를 끝까지 읽고 따른다. 이 파일은 시안 C의 성격만 더한다.

## 한 문장(초안 — 다듬어도 된다)

"그림이 주인공이고 UI는 한지 띠처럼 얇게 — 느티골에 들어가 있는 느낌."

## 스타일

- 주: 에디토리얼·헤리티지(한지 띠, 먹 글자, 세리프 제목, 오방색 점·선). 보조: 이머시브(화면 전체가 하나의 장면, 장면의 빛, 고른 것에 퍼지는 빛).
- 사용자가 가장 재밌다고 한 것이 "조선 느낌의 동네를 걷는 것"이다. 이 시안은 맵과 그림을 가리는 UI를 최소로 한다.
- 글꼴: 제목 Hahmlet, 이야기 글 Gowun Batang(20px 넘게), 정보·단추 Pretendard 또는 Gothic A1.
- 형태:
  - 제목: 그림을 화면 가득(조정자가 만드는 `bg-title-dawn-2400.jpg`가 들어오면 그것, 없으면 지금의 `entrance-spring.jpg`). 하늘 쪽 빈 자리에 큰 세리프 제목, 아래에 한지 띠 하나에 단추들. 해 쪽에 숨 쉬듯 커지는 무리(움직임 줄이기면 멈춤).
  - 맵: 위 띠를 얇은 반투명 한지 띠로(높이를 지금보다 줄인다). 살림·기력·인심은 작은 숫자, 누르면 펼쳐지는 꼴로 생각해도 된다(시안에는 접힌 꼴 + 펼친 꼴 하나). 할 일 쪽지·작은 지도는 가장자리로 붙이고 반투명. 계절 글은 화면 아래 영화 자막처럼.
  - 대화: 위아래 레터박스(얇은 먹 띠)로 장면을 영화처럼. 대사는 아래 띠 안의 큰 세리프 글, 이름은 그 위 작은 주홍 글. "다음 ▼" 대신 화면 가장자리에 "화면을 누르거나 → / Space" 를 아주 연하게(첫 몇 창만). 선택지는 장면 위에 뜨는 한지 쪽지 둘.
  - 한 해 돌아보기: 네 계절의 채색화(지금 배경 그림에서 계절마다 하나씩)를 가로로 이은 두루마리 위에, 계절마다 고른 것과 생긴 일을 짧게. 지금 보는 계절에 빛이 퍼진다.
- 빛: 장면 조명 — 계절·때의 빛(아침 빛), 고른 자리에 퍼지는 빛, 단추에는 가는 테두리 빛. 글 위를 빛이 지나가지 않게.
- 반투명 띠 위의 글도 대비 4.5:1을 지킨다(글 아래에 한지 빛 덮개를 깐다).

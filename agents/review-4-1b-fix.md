## 볼 것

**A. 범위와 세 명령**
- `git diff 3eaea6f --stat`과 새 파일이 지침의 범위 안인가. 앱의 흐름·화면·맵·그림·엔진·꼴 5(`src/screens/**`, `src/plays/**`, `src/map/**`, `src/pixel/**`, `src/art/**`, `src/assets/**`, `game.ts`, `types.ts`, `store.ts`, `storage.ts`, `App`, `content/index.ts`, `content/maps/**`, `src/engine/**`, `src/state/save5.ts`)가 바뀌지 않았는가.

**C. 권고 ㄴ·ㅅ — 새 시험이 잡는가(망가뜨려 보기)**

- ㅅ: `bankRules`의 표가 spec 9.5의 스물여섯 주제(id·문제 수)와 하나하나 같은가(기계로 견줌). 2-1을 60으로, 1-3을 80으로 넣으면 `count`로 잡는가. 표에 없는 은행 주제·`class`·`story`의 규칙이 그대로인가.

## 지킬 것

- 저장소에서 고치는 것은 `review.md`(맨 끝에 절 하나를 더함)뿐이다. 그림을 남기면 git이 무시하는 `docs/shots/review-4-1b-fix/`에 둔다. 코드·시험·spec·docs·agents는 고치지 않는다.
- 커밋·푸시를 하지 않는다. 새 npm 꾸러미, `npx`로 받는 도구, 서비스 워커를 쓰지 않는다. 사파리를 띄우지 않는다. 포트 5173(사용자의 개발 서버)과 다른 세션의 프로세스를 건드리지 않는다.
- 브라우저가 필요하면 개발 서버는 5560~5569, 머리 없는 크롬은 9550~9559만 쓰고 끝나면 끈다.
- 스크래치 폴더는 조정자가 알려 준 스크래치패드 아래 `rv-41b-fix/`다. 복사본·망가뜨려 보기·기록은 거기에 둔다.
- 개인 드라이브의 경로·학교 메일을 저장소·보고에 쓰지 않는다. 지도서·교과서의 글을 저장소에 옮기지 않는다.
- 도우미를 부르면 같은 규칙과 범위를 지키게 하고, 굵은 판단은 내가 다시 본다.

## 할 것

### 1. 권고 A — 빨리 연 직후 곧장 걸을 때의 끊김
- 맵을 연 뒤 쉬는 틈(`paintIdle`)에서, 뒤로 미룬 그림보다 먼저 화면 둘레 띠의 땅을 잘게 칠한다. 띠는 보이는 네모 + 걷는 쪽 2~3칸이다.
- 또는 열기 전에 칠하는 네모(`need`)를 두 칸쯤 넓힌다. 둘 다 해도 된다.
- 목표(CPU 4배 느리게, 1180×820·2, 두 번씩 잼)
  - 아래 넷에서 맵을 연 뒤 10초 동안 50ms 넘는 긴 일 0, 50ms 넘는 장 0.
    - 제목 0.3초 뒤 이어 하기 → 곧장 걷기.
    - 1.5초 뒤 이어 하기 → 곧장 걷기.
    - 계절 닫기 0.3초 뒤 → 곧장 걷기.
    - 연 직후 화면 크기 바꾸기.
  - 지난 바퀴에서 얻은 것을 잃지 않는다.
    - 제목 0.3초 뒤 이어 하기의 기다림 1.5초 안팎(① 1.7초 이하).
    - 닫기 화면 3초 뒤 0.1초 안팎.
    - 걷기 60장.
  - 못 미치면 잰 값과 까닭을 보고한다.

### 6. 판 번호
- `vite.config.ts`의 판 번호가 Cloudflare 빌드 값도 받게 한다.
  - `CF_PAGES_COMMIT_SHA`가 있으면 `YYYYMMDD-<앞 일곱 글자>`.
  - `CF_PAGES_BRANCH`가 `main`이 아니면 뒤에 가지 이름을 붙인다. 예: `20261106-abc1234 · v4-1`.
  - Vercel 값(`VERCEL_GIT_COMMIT_SHA`)은 그대로 받는다. 둘 다 없으면 지금처럼 빌드한 시각.
- 이 이름들은 2026-11-06에 Cloudflare 문서로 본 것이다(11.1의 바). 확인하지 못했다고 적혀 있으니 문서를 다시 보고, 실제로 붙는지는 조정자가 푸시 뒤 본다.

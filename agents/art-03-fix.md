## 수정 범위

- 만들거나 고칠 수 있는 것: `src/assets/pictures/**`의 **위 여덟 파일**과 `docs/pictures.md`(새 줄을 덧붙이고, 다시 만든 세 장의 줄은 고쳐 쓴다 — 옛 지시문은 지우지 말고 "옛 것"으로 남긴다) 뿐이다. 다른 그림은 바꾸지 않는다.
- 코드, 시험, 대본, `docs/pictures-wanted.md`, `review.md`, `spec.md`, `agents/**`를 고치지 않는다. Build 서브에이전트가 지금 같이 코드를 고치고 있다(옆집 자리 `neighbor`와 걱정 표정을 코드에 둔다).
- 작업 파일은 스크래치패드의 `art/` 폴더에 둔다(컴퓨터가 다시 켜져 비었을 수 있다 — 없으면 새로 만든다). 패키지 설치, git 커밋·푸시를 하지 않는다. 사파리를 띄우지 않는다.
- 캔바에서는 그림 생성, 바탕 지우기, 그리고 디자인 「조선에서 한 해 살기 - 화면 시안」(`DAHXV3KUSA4`)에 쪽을 더하고 내보내는 일만 한다. 다른 디자인을 건드리지 않고 새 디자인을 만들지 않는다.

## 만드는 법

- 규격은 그대로(배경 1600×900 JPEG 250KB 안팎, 인물 투명 바탕 높이 1200 WebP 100KB 안팎).
- 그림마다 원본 크기를 열어 눈으로 보고, 참고 그림과 나란히 견준다. 인물은 얼굴·손·가장자리. 기준에 어긋나면 지시문을 고쳐 다시(한 그림에 세 번까지). 그래도 안 되면 가장 나은 것을 넣고 모자란 점을 적는다.
- 걱정 얼굴은 plain과 **나란히 놓아 같은 아이로 보이는지**를 가장 먼저 본다. 같은 아이로 안 보이면 넣지 않는다(넣지 않으면 plain이 나오는 것이 맞다) — 그때는 그렇다고 보고한다.
- 여덟 장을 넣은 뒤 `src/assets/pictures/` 전체가 8MB를 넘지 않는지 본다.

## 끝나면 보고할 것

넣은 그림(파일, 크기, 용량)과 전체 합계, 그림마다 몇 번 만들었는지와 눈으로 본 평가·모자란 점, 같은 곳/같은 아이로 보이는지, 고증에서 사람이 봐야 할 것, 만들지 못한 것과 까닭, 캔바에 남긴 것(쪽 수, 생성 횟수). **모두 끝난 뒤에만 보고한다.** 캔바가 막히면 그때는 바로 알리고 만든 데까지 넣어 둔다.

# Review 서브에이전트 지침 — 태블릿 바퀴 다시 보기

## 맡은 일

네가 `review.md`(태블릿 바퀴)에 적은 것 가운데 Build가 고쳤다고 한 것을 직접 돌려 다시 확인하고, `review.md`에 결과를 덧붙인다. 작은 다시 보기다.

Build가 받은 지침은 `agents/build-01d-fix.md`다. 고치기로 한 것: 1번(꼭)과 권고 2~6번.

## 수정 범위

- 고칠 수 있는 것: `review.md`, `docs/shots/review-1d-2/`. 코드를 고치지 않는다.
- 망가뜨려 보는 시험은 새 복사본에서. 패키지 설치, git 커밋·푸시를 하지 않는다. 5173 서버는 끄지 않는다. 네가 띄운 것은 끝나면 멈춘다. 사파리를 띄우려 하지 않는다.

## 확인할 것

1. `npm run typecheck`, `npm run build`(복사본), `npm test`.
2. **1번**: 큰 갤럭시탭(리눅스라고 말하고 손가락 점이 여럿)으로 꾸민 빌드본에서 안내가 저절로 뜨고 갤럭시탭의 순서만 나오는지, "처음부터"의 물음, 세로 안내, "이 기기"의 기기 줄. 처음에 확인한 다른 기기들(작은 갤럭시탭, 아이패드와 데스크톱 사이트 보기의 아이패드, PC, 홈 화면에서 연 것, 손가락이 닿지 않는 리눅스 컴퓨터, 크롬북, 터치 되는 윈도 노트북)이 어떻게 가려지는지 표로. 잘못 가려지는 경우에 해가 작은지.
3. **2~6번**을 하나씩. 2번은 설치 물음을 꾸며서(와 있는 채로 열기, 읽는 도중에 옴, 받아들임, 그만둠, 추가 알림이 오지 않음). 3번의 고친 글이 5학년에게 분명한지. 4번은 세로에서 자판을 눌러. 5번은 덤을 바로 누르고 금방 마쳐서. 6번은 엔진을 망가뜨렸을 때 시험이 끝나지 않고 멈추는 일이 없는지와, 검사기의 걷기에 둔 한도가 지금 콘텐츠의 검사를 줄이지 않는지(한도에 닿지 않는지).
4. **고치다가 망가진 것이 없는지**: 봄을 두 모습으로 끝까지, 안내가 뜨고 안 뜨는 조건, 새 판 알아차리기, 저장 몇 때, 여섯 크기에서 안내의 넘침, 서비스 워커 없음, 저장의 꼴과 견본 그대로.

## Build의 말 (확인된 사실이 아니다)

- 시험 12파일 472개 통과 + 2개 건너뜀. 빌드 JS 305KB.
- 세 걸음 뒤의 글이 "이제 크롬을 닫고, 홈 화면의 느티나무를 눌러서 열어요."로 바뀌었다(spec 5.4의 "이 창을 닫고"와 달라짐).
- 손가락이 닿는 리눅스 노트북은 갤럭시탭으로 잘못 가려진다. 진짜 설치 물음을 누른 뒤의 흐름은 보지 못했다.
- 세로 안내가 떠 있는 동안 맵이 멈춘다. `promptInstall()`이 답(`accepted`·`dismissed`·`unavailable`)을 돌려준다. 검사기의 걷기에 한도가 생겼다.
- `docs/script-1395.md`가 고쳐진 것으로 나오는 것은 조정자가 한 것이다(뒷산 "한 짐만 하고 쉰다"의 기력 +1을 대본에 맞춰 적음).

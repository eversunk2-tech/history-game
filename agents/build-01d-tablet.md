# Build 서브에이전트 지침 — 태블릿 바퀴 (홈 화면에 추가, 실제 기기에서 쓰기)

## 맡은 일

기획서 `spec.md` 11절 표의 **"태블릿 바퀴(1-다 바로 뒤, 작다)"** 를 만든다. 학생이 갤럭시탭과 아이패드의 크롬에서 `https://joseon-year.vercel.app`을 열어 **홈 화면에 추가**하고 아이콘으로 여는 데 필요한 것들이다. 그리고 1-다의 다시 보기에서 나온 작은 권고들을 함께 고친다.

바퀴 1-다(봄 한 조각)는 커밋 `623b8e1`에 있고 운영 주소에 올라가 있다.

먼저 읽는다: `CLAUDE.md`, `spec.md`의 3절, 5.4, 10절 끝의 "태블릿과 홈 화면"과 "Vercel 설정", 11절의 태블릿 바퀴 줄·"홈 화면"과 "인터넷과 새 판" Review 기준·사용자가 해 볼 점검표, 12.4(T1~T16과 확인하지 못한 것), 13.1의 24~28번. 그리고 `review.md`의 11절(다시 보기)의 30~37번.

## 수정 범위

- 만들거나 고칠 수 있는 것: `src/**`(단 `src/assets/pictures/**`는 빼고), `tests/**`, `public/**`(매니페스트와 아이콘), `index.html`, `scripts/**`(아이콘을 만드는 스크립트), `docs/shots/**`, 프로젝트 설정 파일.
- 고치지 않는 것: `spec.md`, `CLAUDE.md`, `agents/**`, `review.md`, `docs/reviews/**`, `docs/mockup-vn/**`, `docs/pictures.md`, `docs/script-1395.md`, `src/assets/pictures/**`.
- **서비스 워커를 넣지 않는다**(사용자 결정: 인터넷이 있을 때만 연다). 새 패키지를 설치하지 않는다. `vercel.json`은 꼭 필요할 때만 만들고 까닭을 보고한다. git 커밋·푸시를 하지 않는다. 5173 서버는 끄지 않는다.
- 저장의 꼴을 바꾸지 않는다(이번 일에는 필요 없다). 어쩔 수 없이 바꾸면 `SCHEMA`를 올리고 옮기는 함수를 더하며 옛 견본은 지우지 않는다.

## 만들 것

### 가. 홈 화면에 추가 (spec 10절 "태블릿과 홈 화면")

- **매니페스트** `public/manifest.webmanifest`: 이름 "조선에서 한 해 살기", 짧은 이름 "조선 한 해", 화면 가득(`display`), 가로 방향, 바탕 빛과 띠 빛, `start_url`과 `scope`(지금의 `base: './'`와 운영 주소 `https://joseon-year.vercel.app/`에 맞게), `id`, 아이콘 192·512와 maskable 512. spec에 적힌 값을 따른다.
- **아이콘**: 이 게임의 느티나무 도트 그림으로 만든다. 바깥 그림을 쓰지 않는다. `src/pixel`의 그림을 캔버스 없이 정수배로 키워 PNG로 쓰는 작은 스크립트(`scripts/`)를 만들고, 뜬 파일을 `public/icons/`에 둔다(192, 512, maskable 512, 아이패드용 180). maskable은 가장자리가 잘려도 나무가 온전히 보이게 여백을 둔다. 작은 크기에서도 무엇인지 알아볼 수 있어야 한다 — 만든 아이콘을 눈으로 본다.
- **`index.html`**: 매니페스트 링크, 아이패드용 `apple-touch-icon`과 `apple-mobile-web-app-title`, `theme-color`, 빈 아이콘 대신 진짜 파비콘.
- **홈 화면에서 열렸는지 가리기**와 **안내**: 브라우저 탭으로 열었을 때만 제목 화면에 "홈 화면에 추가하면 기록이 안전해요"와 그 기기의 추가 방법 세 걸음을 보인다(갤럭시탭 크롬 / 아이패드 크롬 — spec 5.4의 글). 홈 화면의 아이콘으로 열었으면 띄우지 않는다. PC에서는 띄우지 않거나 한 줄로 줄인다. 안내의 뼈대는 "먼저 홈 화면에 추가하고, 늘 아이콘으로 연다", 그리고 "아이콘으로 열 때도 와이파이가 있어야 해요". 안내는 닫을 수 있고, 닫아도 제목 화면에서 다시 볼 수 있다. 5학년이 읽는 글이다.
- **세로 안내**: 태블릿을 세로로 들었을 때 "가로로 돌려 주세요"를 보인다(매니페스트의 가로 고정이 아이패드에서 듣는지 확인되지 않았다).
- **판 번호와 "이 기기" 줄**: 제목 화면 귀퉁이에 판 번호. "이 기기" 정보(화면 크기, 화소 비율, 홈 화면에서 열렸는지, 저장을 지켜 주는지, 판 번호)를 볼 수 있는 자리를 둔다 — 선생님 자료는 아직 없으니 제목 화면에서 작게 열 수 있게 한다(사용자가 실제 태블릿을 점검할 때 쓴다).
- **새 판 알아차리기**(spec 5.4): 화면이 30분 넘게 가려졌다 돌아왔는데 새 판이 올라와 있으면 저장한 뒤 조용히 다시 불러온다. 새 판인지는 첫 문서를 다시 받아 코드 파일 이름을 견주어 안다. 인터넷이 끊겼거나 받기에 실패하면 아무것도 하지 않는다. 대화나 놀이 도중이면 맵으로 돌아온 뒤에 한다.
- **끊김 알림**은 1-다에서 이미 들어갔다. spec 5.4의 글과 맞는지, 끊긴 동안 아무것도 막지 않는지 본다.

### 나. 1-다 다시 보기의 권고 (review.md 11절)

- **30번**: 해 ☀ 풀이가 붙은 세 줄 알림(79자)이 9초만 뜨고 느티나무 아래에서 주인공을 가리는 것. 읽을 만큼 띄우거나 둘로 나누고, 주인공을 가리지 않는 자리에 띄운다.
- **31번**: 뒷산 "한 짐만 하고 쉰다"가 해 하나를 쓰고 남는 것이 없는 것 → 쉬었으니 기력 +1(spec 5.2의 덤 변화 -1~+1 안). 대본은 고칠 수 없으니, 대본과 달라진 곳을 보고에 적는다.
- **32번**: 기력이 낮으면 다음 계절의 해가 하나 준다는 것을 아이가 알 수 있게 한다(봇짐의 기력 풀이나 계절 닫기의 한 줄).
- **33번**: 덤 줄이 두 줄이 되어 덤을 편 쪽지를 넘겨야 다 보이는 것. **34번**: 봇짐에서 낮은 화면이면 카드가 한 장만 보이고 넘길 수 있다는 표시가 없는 것.
- **37번**: 작은 것들(해 999가 "3/4"로 뜸, 접힌 쪽지의 18px 한 줄, "채비"·"타작 마당"·"값을 치렀어요", 끝까지 가는 시험이 판이 나아가지 않을 때 실패하지 않고 멈춤).
- 35·36번은 손대지 않는다(36번은 다음 바퀴의 Build가 알아야 할 것이다).

## 확인할 것

- `npm run typecheck`, `npm run build`, `npm test`.
- 빌드본(`npm run preview`)을 크롬으로 열어: 개발자 도구의 매니페스트 검사에 오류와 경고가 없는지(머리 없는 크롬으로 설치 가능 여부를 확인할 수 있으면 한다), 아이콘이 다 열리는지, 서비스 워커가 등록되지 않는지, 탭으로 열었을 때와 홈 화면에서 연 것처럼 꾸몄을 때(`display-mode`를 흉내 내어) 안내가 뜨고 안 뜨는지, 세로로 돌렸을 때, "이 기기" 줄, 새 판 알아차리기(빌드를 다시 해서 코드 파일 이름을 바꾸고 30분을 흉내 내어).
- 화면 크기 1024×768, 1024×690, 1080×810, 1280×800, 1366×650, 1920×1080에서 제목 화면의 안내가 넘치지 않는지. 봄을 한 번 끝까지(고친 권고들을 본다).
- 운영 주소에서만 확인할 수 있는 것(매니페스트의 `content-type`, 실제 태블릿에서의 추가)은 "배포한 뒤 확인"으로 보고에 적는다.
- 확인하지 않은 것을 확인했다고 쓰지 않는다. 직접 띄운 서버와 브라우저는 끝나면 멈춘다. 사파리를 띄우려 하지 않는다.

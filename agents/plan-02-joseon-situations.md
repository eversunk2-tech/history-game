사용자가 5학년 2학기 사회 교사용 지도서(아이스크림)를 주었다. 이 지도서를 근거로 **`spec.md`를 고쳐서 게임 상황을 세 가지에서 일곱 가지로 늘린다.** 구현은 하지 않는다. `spec.md`는 아직 사용자 승인 전이다.

## 수정 범위

- 고칠 수 있는 파일: **프로젝트 루트의 `spec.md` 하나뿐**.
- 그 밖의 파일은 읽기만 한다. 패키지 설치, git 커밋·푸시를 하지 않는다.
- **지도서의 글과 그림을 저장소에 옮겨 적지 않는다.** 지도서는 저작물이다. `spec.md`에는 "지도서 2단원 ○차시"처럼 어디를 따랐는지와 짧게 풀어 쓴 내용만 적는다. 풀어 둔 지도서 텍스트 파일을 프로젝트 폴더로 복사하지 않는다.

## 고칠 때 꼭 다룰 것

1. **자료 구조.** 지금은 시기(Era)가 곧 상황이다. "시기 묶음 → 상황(대표 해)"의 두 단으로 바꾼다. 3단원(일제 강점기~6·25)을 나중에 상황으로 더할 수 있어야 하므로, 역할·수치 시작 값·견주기 물음이 상황마다 달라질 수 있게 한다(예: 1899년에는 법으로 신분이 없어졌다). 3단원은 이번에 기획하지 않는다. 지도서 3단원의 차시 구성만 훑어 "나중에 더할 수 있다"는 것을 한 문단으로 적는다.
2. **새 상황 네 가지의 구성.** 기존 세 상황과 같은 꼴로 "이 상황만의 규칙"과 예시 장면을 상황마다 **네댓 개**씩 쓴다. 1899년 상황은 가상의 마을과 한성을 어떻게 잇는지, 역할을 어떻게 둘지 정한다.
3. **견주기 물음.** 일곱 물음 표를 일곱 상황에 맞게 다시 짠다. 상황이 늘어 표가 넓어지면 보는 방법(예: 고른 두 상황만 나란히)을 정한다.
4. **지도서 활동과의 연결.** 끝 화면의 "내가 겪은 사례"를 4~5차시 평가(가상 일기 쓰기)의 재료로 쓰게 하고, 병자호란 상황은 7차시의 주장 정하기, 1899년 상황은 11~12차시 역할극과 이어지게 한다. 2절의 표에 차시를 적는다.
5. **분량과 순서.** 상황이 일곱이면 장면이 몇 개인지 다시 세고, 첫 구현 범위와 묶음 순서를 다시 짠다. 한꺼번에 다 만들지, 상황 하나를 끝까지 만들어 본 뒤 늘릴지 권장안을 내고 "사용자 결정 필요"에 올린다.
6. **고증.** 새 상황의 사실은 지도서와 믿을 만한 자료(우리역사넷, 한국민족문화대백과, 국립중앙박물관 등)로 확인하고 12절에 근거를 더한다. 지도서로 확인한 것은 "지도서 ○차시"로 적는다. 확인하지 못한 것은 쓰지 않거나 12.3에 올린다. 병자호란과 개항 이후는 다른 나라와 얽힌 내용이다. 초등 5학년 수위와 7절의 원칙을 지킨다.
7. **이미 풀린 불확실 사항 정리.** 12.3의 2번(교과서의 시기 구분)은 지도서로 확인되었으니 고친다. 6.1의 시기 구분 설명과 시기 고르기 화면의 안내 문장도 맞춘다. 12.2의 화성 완공 시점(8월·9월)은 화성 장면을 남길 때만 다시 확인한다.
8. **길이.** 사용자가 읽고 승인할 문서다. **520행을 넘기지 않는다.** 넘을 것 같으면 예시 장면을 줄인다. 맨 위에 "무엇이 바뀌었나"를 다섯 줄 안팎으로 적는다.

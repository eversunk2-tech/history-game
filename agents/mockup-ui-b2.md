# 시안 B 다듬기 — 주 단추의 색(조정자)

사용자가 세 시안 가운데 **B 「단청 그림책」을 골랐다**(2026-11-11). 그리고 "버튼을 빨간색 말고 좀 더 어울리는 다른 색으로 바꿔서 보여 달라"고 했다. 처음 지침(`agents/mockup-ui-common.md`, `agents/mockup-ui-b.md`)의 규칙은 그대로다.

## 할 것

1. **후보 색 셋**을 정한다. 지금 주홍(#c4462a)이 맡던 자리 — "이어 하기"·"다음 ▶" 같은 주 단추, 그 단추의 그림자·하이라이트·누름 — 에 들어갈 색이다. 단청·한지와 어울리고 5학년 눈에 "누를 곳"으로 바로 보이는 색으로. 예(정하는 것은 너다): 단청의 녹청(뇌록) 계열, 쪽빛(남색) 계열, 송화·황토(황) 계열, 먹·밤색 계열.
   - 화면에 이미 쓰인 색과 겹쳐 뜻이 헷갈리지 않게 한다: 계절 색(봄 #7fa650, 여름 #2f8a76, 가을 #c07f24, 겨울 #64809c — 계절 칩·도장), 초점 테(청 3px), "꼭 할 일"의 붉은 네모, 잠김(점선·자물쇠), 젤리 막대. 주 단추 색을 바꾸면서 초점 테나 다른 표시의 색도 바꿔야 하면 함께 바꾸고 적는다.
   - 흰 글자(또는 진한 글자)와의 대비 4.5:1 이상. 누름·초점·잠김 상태도 그 색에 맞춘다.
   - 빨강(주홍)은 이제 주 단추에서 뺀다. "꼭 할 일" 같은 작은 표시에 남기는 것은 된다.
2. 후보마다 **같은 네 화면**(제목·맵·대화·한 해 돌아보기)을 찍은 `sheet` 한 장. 후보끼리 한눈에 견줄 수 있게, 주 단추가 크게 보이는 조각(제목의 "이어 하기"·"처음부터", 돌아보기의 "다음 ▶", 고르기 화면의 선택 카드)을 모은 **견줌 한 장**(`compare-buttons.jpg`)도 만든다.
3. 셋 가운데 **권하는 하나**와 까닭(한두 줄).
4. 만드는 곳: `docs/mockup-ui/b/colors/` 아래(예: `colors/1-<이름>/`, `colors/compare-buttons.jpg`). 처음 B(`docs/mockup-ui/b/` 의 나머지 파일)는 그대로 두어 견줄 수 있게 한다 — 색을 CSS 토큰 하나로 바꿔 끼울 수 있으면 그 꼴로(예: `index.html?btn=1`). `DESIGN.md`에 "주 단추 색 후보" 절을 더해 색 값·대비·바꾼 토큰을 적는다.

# Build 서브에이전트 지침 — 바퀴 1-가 (게임의 틀)

## 맡은 일

「조선에서 한 해 살기」의 **틀**을 만든다. 기획서 `spec.md`의 11절 표에서 "1-가" 줄이 이번 범위다.
끝나면 농민 집 아이로 ① 1395년 상황 한 판(8장면)을 제목 화면부터 한 해 돌아보기까지 브라우저에서 끝까지 할 수 있어야 한다.

먼저 `CLAUDE.md`와 `spec.md` 전체를 읽는다. 특히 4절(화면 1~6번), 5절(규칙), 6.3(① 예시 장면), 7절(역할과 수위 원칙), 9절(화면), 10절(기술·파일 구조·자료의 꼴), 11절(1-가 줄과 Review 통과 기준).

## 수정 범위

- 만들거나 고칠 수 있는 것: `package.json`, `package-lock.json`, `index.html`, `tsconfig.json`, `vite.config.ts`, `.gitignore`, `src/**`, `tests/**`, `.claude/launch.json`.
- 고치지 않는 것: `spec.md`, `CLAUDE.md`, `agents/**`, `docs/**`, 프로젝트 폴더 밖의 모든 것.
- `spec.md`와 다르게 만들어야 할 까닭이 생기면 `spec.md`를 고치지 말고 그렇게 만든 뒤 보고에 적는다.
- git 커밋·푸시를 하지 않는다.
- 설치해도 되는 패키지는 사용자가 승인한 일곱 개뿐이다: `vite`, `typescript`, `preact`, `@preact/preset-vite`, `@preact/signals`, `vitest`, `pretendard`. 다른 패키지가 꼭 필요하면 설치하지 말고 멈춰서 보고한다. Node v24, npm 11이 깔려 있다.

## 이번에 만드는 것

1. **프로젝트 틀.** Vite + TypeScript(strict) + Preact + @preact/signals. npm 스크립트 `dev`, `build`, `preview`, `test`(vitest run), `typecheck`(tsc --noEmit). `.gitignore`(node_modules, dist, .DS_Store). 패키지 이름은 `joseon-year`.
2. **규칙 엔진** `src/engine` — 화면·브라우저·시간을 모르는 순수 함수. spec 10절의 꼴을 따른다.
   - 새 판 만들기, 지금 장면, 고르기, 다음으로, 끝내기. 한 판은 정확히 8장면(계절마다 내 장면 1 + 세상 장면 1, 차례는 장면 자료의 `order`).
   - 수치 세 가지 0~10 범위 유지, 선택 하나의 변화 -3~+3.
   - 잠긴 선택지 판정과 보여 줄 까닭, 결과 갈림(`variants`), 표시(flag)와 카드 모으기.
   - 씨앗을 받는 난수와 여름 날씨 뽑기(가뭄 3 · 보통 5 · 풍년 2). 봄에 고른 농사법과 날씨가 만나 결과가 갈리게 한다. 같은 씨앗이면 같은 판이 나와야 한다.
   - 수치가 0이 되어도 판이 끝나지 않는다.
   - 한 해 돌아보기에 쓸 것: 계절마다 고른 일, 수치의 흐름, 올해의 바람이 이루어졌는지와 그 까닭, "한 해 이름"(다섯 가지쯤, 수치와 선택으로 가린다), 뒷이야기.
3. **콘텐츠** `src/content`
   - `groups.ts`(시기 묶음 4), `themes.ts`(견주기 물음 7), `cards.ts`, `sources.ts`(이번 장면이 쓰는 근거 번호 — spec 12.2의 번호·사실·출처를 그대로 옮긴다).
   - `situations/s1395/` — 상황 정의, 세상 장면 4개, 농민 집 장면 4개. **이번에는 농민 집만 할 수 있는 견본이다.**
     - spec 6.3의 예시 장면(봄 세상, 봄 농민, 가을 세상, 겨울 세상)은 그대로 쓴다.
     - 예시가 없는 네 장면(여름 세상, 여름 농민, 가을 농민, 겨울 농민)은 견본으로 새로 쓴다. spec 6.2의 ① 칸과 6.3의 "이 상황만의 규칙", 12.2의 근거 안에서만 쓴다. 근거 목록에 없는 연도·제도 이름·숫자를 넣지 않는다. 12.3에 "확인하지 못했다"고 적힌 것을 사실처럼 쓰지 않는다. 이 네 장면에는 자료에 견본 표시를 달아 둔다(1-나에서 대본을 쓰며 다시 다듬는다).
     - 여름 장면 가운데 하나에서 날씨 뽑기가 드러나야 한다.
   - 나머지 여섯 상황은 이름·대표 해·한 줄 소개만 있는 "준비 중" 항목으로 둔다(spec 6.1 표).
   - **자료만 더하면 풀리게 만든다.** 1-나에서 다른 세 집의 장면 파일을 더하면 코드 수정 없이 그 집을 할 수 있어야 하고, 나중에 상황 폴더를 더하면 "준비 중"이 풀려야 한다. 아직 장면이 없는 집은 뽑기에서 빠지거나 "준비 중"으로 보이게 한다.
   - `validate.ts` — spec 11절 "콘텐츠 검사기" 항목을 검사한다. 아직 다 채우지 않은 상황은 "있는 집에 대해서만" 빠짐없는지 보고, 무엇이 비었는지 알려 준다. 쓰지 않기로 한 낱말 목록(낮춰 부르는 말 등)은 7절 원칙에서 뽑아 만든다.
4. **화면** `src/screens`, `src/ui`, `src/state` — spec 4절 1~6번.
   - 제목 → 시기와 상황 고르기(다른 상황은 "준비 중") → 태어날 집 뽑기 → 나를 소개합니다 → 계절 × 4(계절 열기 → 장면 → 고르기 → 결과와 배움 쪽지 → 장면 → 고르기 → 결과 → 계절 닫기) → 한 해 돌아보기 → 다시 하기.
   - 견주어 보기, 생각 나눔, 수첩, 선생님 자료는 **이번에 만들지 않는다**(제목 화면의 단추는 "준비 중"으로 둔다).
   - 배치는 9절: 가로 화면, 왼쪽 6할 그림 자리, 오른쪽 4할 지문과 선택지, 위에 계절 띠와 수치 세 개. 본문 20px 이상, 선택지 단추 높이 56px 이상. 1024×768에서 가로 스크롤과 글자 잘림이 없어야 하고 1920×1080에서는 비율대로 커진다.
   - 그림은 **임시 도형**이면 된다(계절 색 바탕과 단순한 모양). 그림 그리는 코드는 `src/art`에 두고, 1-나에서 제대로 된 그림으로 갈아 끼울 수 있게 장소·계절·인물을 이름으로 부르는 꼴로 만든다. 외부 그림 파일을 쓰지 않는다.
   - 잠긴 선택지는 흐리게 보이고 자물쇠 표시와 까닭 한 줄이 붙는다. 결과 화면의 수치 변화는 화살표와 글자로 함께 보인다(색만으로 알리지 않는다).
   - 맞음·틀림 표시, 점수, 등수, 시간 제한을 어디에도 넣지 않는다.
   - 기기 저장: localStorage `joseon-year/v1`에 해 본 조합, 모은 카드, 첫 판을 했는지. 저장을 못 쓰는 환경에서도 게임은 돌아야 한다.
5. **시험** `tests`
   - `engine.test.ts`: 수치 범위, 잠김 판정, 결과 갈림, 같은 씨앗 같은 결과, 정확히 8장면.
   - `content.test.ts`: 검사기가 지금 자료를 통과시키는지, 일부러 망가뜨린 자료를 잡아내는지.
   - `playthrough.test.ts`: 농민 집으로 무작위 1,000판을 돌려 오류 0, 모든 "한 해 이름"이 한 번 이상 나오는지.
6. **미리 보기 설정** `.claude/launch.json` — 이름 `history-game`, `npm run dev`, 포트 5173.

## 글과 말투

- spec 5절 10번의 글자 수 예산(지문 100자, 선택지 26자, 결과 90자, 배움 쪽지 50자)과 11번의 말투(지문·결과는 "나"의 이야기체, 배움 쪽지는 "~했어요")를 지킨다.
- 화면에 보이는 모든 글은 초등 5학년이 읽는다. 쉬운 우리말로 쓴다.
- 지도서·교과서·다른 게임의 문장과 그림을 가져오지 않는다.

## 스스로 확인할 것

끝났다고 보고하기 전에 직접 돌려 본다.

- `npm run typecheck`, `npm run build`, `npm test`가 모두 통과한다.
- 개발 서버를 띄워 1024×768 크기에서 제목부터 한 해 돌아보기까지 한 판을 끝까지 해 본다. 브라우저 도구를 쓸 수 없으면 하지 못했다고 적는다.
- 확인하지 않은 것을 확인했다고 쓰지 않는다.

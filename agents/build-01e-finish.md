# Build 서브에이전트 지침 — 바퀴 1-라 마무리 (4판 승인 뒤)

## 맡은 일

바퀴 1-라의 고치기(`agents/build-01e-fix.md`)를 하던 Build가 **중간에 멈췄다**(저장 꼴 4의 시험을 고치던 참 — "Now I'll update the storage tests for schema 4…"). 그 사이에 게임의 짜임이 바뀌었다: 사용자가 2026-10-30에 기획서 **4판**(`spec.md`, 거점 마을 + 에피소드 출전 RPG)을 권장안대로 승인했다. 4판 **10.6절**이 1-라 작업물을 어떻게 끝낼지 정했다 — **새 짜임에서도 남는 고치기만 마치고 커밋한다.**

너는 그 마무리를 한다. 먼저 읽는다: `spec.md` 10.6절(전부), `agents/build-01e-fix.md`(고칠 것의 원래 지침 — 수정 범위·확인·일하는 방법은 그대로 따른다), `review.md` 3절(번호별 문제와 고칠 안), 5.2·5.3절(글의 안).

작업 폴더에는 이미 고친 것이 많다(`git diff --stat HEAD`로 74파일, 커밋되지 않음). **처음부터 다시 하지 않는다.** 번호마다 지금 코드에 들어가 있는지 먼저 보고, 빠진 것만 한다.

## 할 것

1. **멈춘 곳부터**: 저장 꼴 4(`src/state/storage.ts`의 `SCHEMA = 4`)와 3 → 4 옮기기, 41번(깬 기록)이 맞게 들어갔는지 보고, 시험(`tests/storage.test.ts` 등)을 꼴 4에 맞게 마친다. 옛 판(`4a1d0a6`)이 꼴 4 저장을 건드리지 않고 "게임을 새로 받아야 해요"를 알리는지도 1-라 지침대로 확인한다.
2. **들어갔다고 보이는 것 — 확인만**(빠졌거나 덜 됐으면 고친다): 1~10, 12~15, 18·19, 30~32, 34㉡, 35, 41번.
3. **남았으면 마무리**(새 짜임에서도 쓴다): 17(김매기 — 누를 때만 뽑힘, 40~70초), 20(베 짜기 "여기서 그만 짜도 돼요"와 주인공 머리), 23~26(맵의 알림·누름·화살표·㉠㉣㉤㉥㉨), 27(지난 이야기의 `MoreBox`), 28·29(자판과 초점, 화면), 36(그림 미리 받기의 차례), 37(겹친 코드).
4. **하지 않는다**(4판에서 필요 없어짐): 11(계절 닫기의 값), 16, **21의 화면 쪽**(한 해 돌아보기 줄이기·넉 장 만들기 — 가을 대화를 줄이는 **글** 쪽은 이미 했으면 그대로 둔다), 22(해 풀이 알림), 33("처음부터" 물음), 34㉠(실제 옛 판 저장 견본), 38~47. 4판의 새 일(거점·겨루기·서당·레벨 등)도 하지 않는다.

`build-01e-fix.md`가 3·4번과 다르게 말하는 곳은 이 지침을 따른다. 이미 해 둔 11·21·22·33·34㉠의 코드가 있으면 지우지 말고 그대로 두고 보고에 적는다(지우는 일은 4판 Build가 한다).

## 수정 범위

`agents/build-01e-fix.md`의 "수정 범위"와 같다. 다시 적으면:
- 고칠 수 있는 것: `src/**`(`src/assets/pictures/**`는 빼고), `tests/**`, `docs/script-1395.md`, `docs/pictures-wanted.md`, `docs/shots/**`, `scripts/**`, `index.html`, 프로젝트 설정 파일.
- 고치지 않는 것: `spec.md`, `docs/spec-3판.md`, `CLAUDE.md`, `agents/**`, `review.md`, `docs/reviews/**`, `docs/mockup-vn/**`, `docs/pictures.md`, `src/assets/pictures/**`.
- 서비스 워커와 새 패키지는 안 된다. git 커밋·푸시와 작업 폴더를 바꾸는 git 명령(`stash`·`checkout`·`reset`)을 하지 않는다. 옛 판 빌드는 스크래치패드에 `git archive 4a1d0a6 | tar -x`로.
- **포트 5173에 띄우지 않는다**(사용자의 자리 — 띄워 두었으면 끄지 않는다). `npx vite --port 5174`처럼. 다른 프로젝트·다른 세션의 서버와 머리 없는 크롬은 건드리지 않는다. 사파리를 띄우지 않는다. 네가 띄운 것은 끝나면 멈춘다.

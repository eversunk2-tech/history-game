그림에서 따를 것은 **구도**다.

- 화면 가득 채운 배경 그림(장소).
- 가운데에 서 있는 인물 한 명(무릎 위쯤까지 보이는 서 있는 그림).

**따르지 않을 것**: 그 게임의 인물·배경·장식을 베끼지 않는다(남의 저작물이다). 인물의 생김새·옷차림도 가져오지 않는다. 우리 인물은 조선 시대 옷차림의 열다섯 살이고, 초등학교 교실에서 쓰기에 알맞게 그린다. 참고 그림을 저장소에 넣지 않는다.

## spec에 반영할 것

1. **9절(화면과 그림 방향)을 미연시 구도로 다시 쓴다.**
   - 지금의 "왼쪽 6할 그림, 오른쪽 4할 글" 배치를 버리고: 화면 가득 배경 + 서 있는 인물 + 아래 대화창.
   - 지문·결과는 아래 대화창에 나온다. 말하는 사람이 있으면 대화창 위에 이름표(예: "아버지", "사또")를 단다. 지문은 "나"의 이야기체이므로 이름표가 없는 때가 기본이다.
   - 글이 길면 대화창을 **눌러서 넘긴다**(한 번에 두세 줄). 넘길 것이 남았으면 ▼ 표시.
   - 선택지는 배경 위 가운데에 세로로 놓인 단추 2~3개로 나온다. 잠긴 선택지와 까닭 한 줄도 같은 자리에 보인다.
   - 결과 → 수치 변화 → 배움 쪽지 → 얻은 카드를 어떤 순서와 모양으로 보일지 정한다(대화창을 넘기는 흐름 안에서).
   - 수치 세 개와 계절 띠는 화면 위쪽에 작고 얇게 둔다(배경을 가리지 않게).
   - 장면에 **등장인물**을 세울 수 있게 한다(주인공만이 아니라 아버지, 이웃 어른, 사또, 장사꾼 등). 인물은 표정이나 몸짓을 두세 가지 가질 수 있다. 꼴에 필요한 칸(장면의 등장인물, 말하는 사람)을 10절에 더한다.
   - 글자 크기 기준(본문 20px 이상, 단추 56px 이상)과 화면 크기 기준(1024×690 포함)은 그대로 지킨다. 대화창이 화면의 얼마를 차지하는지, 1024×690에서 100자 지문이 몇 번에 나뉘어 나오는지 셈해 본다.
   - 색만으로 뜻을 전하지 않는다, 소리 없음, 맞음·틀림 표시 없음은 그대로다.
2. **그림을 어떻게 마련할지는 사용자에게 묻고 있다(아직 정해지지 않음).** 세 가지 길이 있다: ㉠ 그림 생성 도구로 만든 배경·인물 그림 파일을 쓴다 ㉡ 지금처럼 코드(SVG)로 그린다 ㉢ 사용자가 그림 파일을 만들어 넣는다. 어느 쪽이 되어도 되도록 spec을 쓴다.
   - 그림 층은 **이름으로 부르는 자리**(배경 = 상황·장소·계절, 인물 = 누구·표정)로 두고, 그 자리에 코드로 그린 그림과 그림 파일(PNG·WebP) 어느 것이든 꽂을 수 있게 한다. 그림 파일이 없으면 코드로 그린 그림이 나온다.
   - 그림 파일을 쓸 때 필요한 것을 적는다: 파일 두는 곳, 이름 규칙, 권장 크기와 비율(배경은 가로 화면, 인물은 투명 바탕), 용량 한도(오프라인으로 끝까지 되어야 한다), 출처 적는 곳.
   - 고증 주의: 옷·머리 모양·건물은 확인되지 않은 것이 많다(12.3). 그림을 만들 때 지킬 기준(예: 시대에 없던 물건을 넣지 않는다, 옷차림은 단순하게)을 적고, Review가 그림도 본다고 11절에 적는다.
   - "그림은 모두 코드로 그린다"고 적힌 곳(1절, 9절, 14절 등)을 이 결정이 날 때까지 "그림 마련 방법은 13.2에서 정한다"로 고친다. 13.2에 이 결정을 "1-나의 그림 작업 전에 필요한 것"으로 올린다.
3. **4절(게임 흐름)과 5절(글자 수 예산)** 이 새 구도와 맞는지 본다. 화면 수와 눌러 넘기는 횟수가 늘면 한 판 시간이 길어진다. 한 판 10분 안팎을 지킬 수 있는지 셈하고, 필요하면 예산을 고친다.
4. **11절**: 1-나에 "화면을 미연시 구도로 바꾸기"를 넣는다. 1-가에서 만든 화면(왼쪽 그림·오른쪽 글)을 고치는 일이므로 1-나의 맨 앞쪽 일이다. 1-나가 너무 커지면 나누는 안을 적는다(예: 1-나 = 구도 바꾸기 + ① 20장면과 대본, 1-다 = 그림과 끝 화면). 사용자가 처음 해 보는 때가 언제인지 밝힌다.
5. 15절의 ① 줄 위에 "화면 전체" 줄을 하나 만들어 이 의견(2026-10-08, 미연시 구도)을 적고, 반영할 바퀴를 적는다.

길이 한도는 **600행**으로 늘린다.

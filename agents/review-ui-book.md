## 볼 것

1. **세 명령**: `npm run typecheck` 오류 0, `npm test -- --no-cache --configLoader runner` 실패 0(시험 수, 지운 시험과 까닭), `npm run build` JS 하나·`import(` 0·미리 받기 두 줄(그림·주아) 그대로. 빌드본 JS에 `open2`·`devOpenShelf`가 없는지 직접 찾는다.
2. **범위**: 바뀐 파일이 `spec.md` 12.7의 표 + 곁일(`RolePick.tsx`의 되풀이 키)뿐인가. 12.7의 "고치지 않는 것"(`src/content/**`, `src/state/**`, `src/ui/year.ts`, `src/ui/More.tsx`, 다른 화면, 저장)이 그대로인가. `RolePick.tsx`에서 되풀이 키 말고 바뀐 것이 없는가. 누가 될까의 모습이 `.book, .rolepick` 묶음을 나눈 뒤에도 그대로인가(㉠의 Review 그림 `docs/shots/review-ui-a/`와 같은 크기에서 견준다).
3. **게임의 글이 한 글자도 바뀌지 않았나**(12.5): 이야기책의 글 — 머리, 안내 줄, "이야기책", 두 주제(안내 줄의 말 그대로), 일곱 이야기의 해·제목·소개 글, "펼치기 ▶"·"다시 살기 ▶"·"준비 중"·"한 해 이름"·"깬 이야기 · …"·"살아 본 모습: …" — 과 읽는 글(aria)의 규칙. 바뀐 화면 글을 모두 뽑아 `983ad3b`와 견준다.
4. **동작**(12.6): 열린 줄·표지를 누르면 `openStory` → 누가 될까, 준비 중은 누를 수 없음(`div role="group"`), "처음으로"는 `backToTitle`, 방금 깨고 돌아왔을 때만 도장이 찍히는 움직임(다시 그려져도 다시 찍히지 않음), 표지가 다시 그릴 때 넘어가지 않음(12.12의 5). `coverStory`의 고르기 셋(방금 깸 → 안 깬 열린 것 가운데 앞 → 다 깼으면 가장 뒤)을 시험과 따로 화면에서 확인. 마우스·손가락(`Input.dispatchTouchEvent`)·Enter·Space, 잇달아 누름이 한 번만 받히는지.
5. **화면**(머리 없는 크롬 + CDP, 여덟 설정 × (가)(나)(다)): 6.2의 표대로 — 글 잘림·가로 넘침·겹침 0(목차의 넘겨 보는 칸은 "아래에 더 있어요 ▼"가 붙을 때만 뺀다), 문장 20px·꼬리표 18px, 누름 56px, 대비 4.5:1(큰 글·테·초점 3:1 — **도장 자리와 그림 위의 글은 화소로**), 움직임 줄이기(움직임 0, 도장은 처음부터 찍힘), Tab 차례(처음으로 → 목차의 열린 줄 → 표지)와 먹 초점 테(표지는 면 안쪽 — 비단 표지 위에서 묻히지 않는지), `aria-current`. **(다) 1024×768의 목차가 꽉 찬 것**은 글꼴이 조금 넓어져도 넘치지 않는지(예: 글자 너비를 1~2% 늘린 대신 글꼴로 한 번) 보고, 넘치면 "아래에 더 있어요 ▼"가 붙는지 본다. 시안 A의 같은 상태·크기 그림과 나란히 놓아 크게 다른 곳이 있는지.
6. **도장과 돌아보기 3장**: 도장이 뇌록 세 겹 테·글 `--rok-edge`·안 종이 빛 94%인가, 붉은 값이 남지 않았는가(이야기책·돌아보기 모두). 필터 `#rough`가 없거나 안 먹을 때 도장이 사라지지 않는가. 한 해 돌아보기 3장(1024×768·1180×820·1920×1080)에서 큰 도장이 잘리거나 겹치지 않는가. 한 해 이름이 가장 긴 것(이야기의 결말 가운데 가장 긴 이름)으로도 도장이 액자·종이 밖으로 넘치지 않는가.
7. **표지 그림**: 늦춘 망(10Mbps·40ms·CPU 4배, 캐시 없음)으로 빌드본을 열어 이야기책 액자가 비는 시간을 직접 잰다(제목이 뜨자마자 / 1초 뒤 "처음부터"). 그림을 받지 못할 때 액자가 한지 빛으로 남고 오류가 없는가. 이야기책에서 받은 그림을 대화 장면이 다시 받지 않는가(망 기록).
8. **곁일**: 누가 될까에서 Enter·Space를 1.5초 넘게 누르고 있을 때 종이에 머무는가(보통·움직임 줄이기, 개발판·빌드본), 손을 뗀 뒤 한 번 누르면 넘어가는가, ㉠ 고침의 380ms 막음이 그대로인가.
9. **망가뜨려 보기**(스크래치 사본에서만): 새 시험이 실제로 잡는지 — 예: 도장을 붉은 값으로, 쪽빛 면을 둘로, 목차 줄 `min-height`를 3rem으로, 소개 글을 1rem으로, 표지를 `useMemo`/매번 셈으로 바꾸기, `aria-current` 빼기, 준비 중을 `button`으로, `coverStory`의 고르기 차례 바꾸기, `themeOf`의 묶음 바꾸기, `?book=open2`의 DEV 막음 빼기, 화면 글 한 글자 바꾸기, `ev.repeat` 막음 빼기, `stamp-press`를 줄이기 설정 밖으로. 못 잡는 것을 적는다.
10. **코드**: 새 코드의 버그·죽은 코드·타입 우회·이름 겹침, 옛 이야기책 CSS가 남아 다른 화면에 새지 않는가, `RoughFilter`가 화면 읽기에 잡히지 않고(`aria-hidden`) 누름을 막지 않는가, 개발용 길이 학생판에서 열릴 길이 없는가. 개인 정보 검사: 바뀐·새 파일에 조정자가 따로 알려 준 민감 낱말 목록(개인 드라이브 경로·학교 메일·학교 이름 등 — 낱말 목록은 어느 파일에도 옮겨 적지 않는다)과 스크래치 경로가 없는가.
11. **WebKit**(아이패드 크롬)은 여기서 볼 수 없다. 사용자가 기기에서 볼 것을 짧은 목록으로 적는다.

# 맵 그림 올리기 시안(기획서 4.7.5)

기획서 `spec.md` 4.7.5 "맵 그림 올리기(4판 고침 3)"의 시안이다. 사용자가 보고 화풍을 정하는 그림이고, 게임 코드가 아니다. `src/`는 고치지 않았다.

| 판 | 무엇 | 사용자의 말 |
|---|---|---|
| 첫 시안 `v1/` | 규칙(먹빛 테두리·빛 하나·무리 짓기)으로 깔끔하게 | "깔끔해졌지만 너무 단조롭다" |
| 2차 시안 `v2/` | 큰 얼룩·소품·폭신한 나무를 되살림 | "훨씬 괜찮지만 차갑고 자로 잰 듯 기하학적이다" |
| 3차 시안 `v3/` | 지금 그림에서 출발해 같은 맛을 2배로 곱게. 사람 테두리 (가)·(나) | 사람은 (나)로 정함. 화풍은 3차의 방향을 지키되 때와 큰 얼룩을 덜어 낸 것을 한 번 더 본다 |
| **3.1차 시안**(이 폴더) | 3차에서 집·담·대문의 때 자국, 흙길의 크고 진한 얼룩, 담 돌의 어지러운 빛깔을 덜어 냄 — 지금 권하는 것 | (보고 정한다 — 기획서 13.2의 34번) |

## 자리와 크기

- **자리**: 느티골(봄) 마을 안 대문 앞 — 대문(51,27칸) 앞, 1-라 화면 `docs/shots/1e-finish/oc-spring-manorfront.jpg`의 자리. 위 띠·할 일 상자·작은 지도는 뺐다.
- **크기**: 아이패드 1024×768 화면을 기기 화소 그대로(화소 비율 2) 2046×1536으로 찍었다. 지금 그림은 맵 점 하나 = 6화소, 시안은 그림 점 하나 = 3화소(맵 점 하나 = 6화소로 같다). **사람의 화면 키가 모두 192화소(CSS 96)로 같다** — 사용자 결정 50번.
- **놓은 것**(모두 맵 자료의 그 자리에 실제로 있다): 기와 담과 대문, 초가 한 채, 흙길과 마당, 풀밭, 꽃나무 셋(담 안의 흰 꽃나무 포함), 참나무, 장독대 둘, 우물, 너럭돌, 싸리 울타리·돌담, 풀포기·들꽃·잔돌, 닭과 까치, 사람 셋(주인공 남자아이, 마을 어른, 우물가 아주머니). 담 안의 사랑채는 화면 위 끝에 조금 걸려 모두에서 뺐다.

## 다시 만드는 법

프로젝트 폴더에서(새 패키지 없음 — Node와 이미 있는 Vite만 쓴다):

```
node docs/mockup-art/make-before.mjs      # 지금 그림 + region.json + before-metrics.json
node docs/mockup-art/v3/make-v3.mjs       # 3차 시안(그대로 다시 나온다)
node docs/mockup-art/make-v31.mjs         # 3.1차 시안
node docs/mockup-art/make-compare.mjs     # 지금 · 3차 · 3.1차를 나란히 + compare-metrics.md
```

- 첫·2차 시안은 `node docs/mockup-art/v1/make-after.mjs`, `node docs/mockup-art/v2/make-v2.mjs`로 다시 만든다.
- `make-before.mjs`와 3·3.1차 스크립트는 `scripts/make-icons.mjs`처럼 Vite로 `src/`의 TypeScript를 읽어 게임의 그림 함수(땅 `paintGround`, 나무갓 `canopy`·`trunk`·`branch`, 봄 64색 벌)를 부른다. **읽기만 한다.**

## 3차에서 3.1차로 무엇을 얼마나 덜었나

| 덜어 낸 것 | 어떻게 | 수치(3차 → 3.1차) |
|---|---|---|
| 집·담·대문의 때 자국 | 수채화 얼룩의 큰 결 ×0.6, 고운 결 ×0.55, 짚 결 ×0.5, 어둡게 옮기는 문턱을 밝게 옮기는 문턱보다 높게 | 얼룩이 한 칸 어둡게 만든 점: 대문 8.8 → 2.9%, 초가 15.3 → 6.0%, 담 9.5 → 1.9% |
| 초가 지붕의 거뭇함 | 둥근 지붕의 명암을 한 단계 밝게(짚 결은 그대로) | 위와 같음 |
| 흙길의 크고 진한 얼룩 | 문턱으로 자른 얼룩 대신, 크고 느린 결(맵 점 서른~마흔 칸)에 비례해 조금씩 섞어 부드럽게 번지게 | 흙의 얼룩덜룩함 4.10 → 3.61(지금 3.46) · 큰 결 밝기 5.75 → 6.32(지금 5.43 이상 유지) |
| 잿빛 얼룩과 잿빛 그늘 | 잿빛 얼룩(#9c8c78) 대신 볕에 바랜 모래빛, 잿빛으로 가라앉은 흙(우물 둘레의 그늘 등)은 따뜻한 밤빛 쪽으로 | 어두운 점의 따뜻함 +6.8 → +6.7, 화면의 따뜻함 50.2 → 50.0 |
| 담 돌의 어지러운 빛깔 | 주황 돌(흙빛 그대로) 대신 따뜻한 잿빛(흙빛을 반만 섞은 돌)을 여섯에 하나쯤. 크기의 들쭉날쭉함은 남김 | (눈으로 본다 — `compare-scene.png`) |
| (덤) 사람의 (나) 테두리 | 곁의 빛깔에 섞는 밤빛을 0.6 → 0.68로 조금 짙게 — 그늘 얼룩 위에서도 묻히지 않게 | 사람 바깥과 바닥의 밝기 차 0.31~0.37 → 0.32~0.40 |

3차에서 좋았던 것(따뜻한 빛깔, 먹빛 테두리 없는 배경, 지금 그림을 이은 나무와 풀밭의 결, 소품과 짐승)은 그대로다.

## 수치(`compare-metrics.md`의 요약)

| 수치 | 지금 | 3차 | 3.1차 | 기준 |
|---|---|---|---|---|
| 풀빛의 평균 색상각 | 100° | 97.7° | 97.3° | 95~105° |
| 화면 전체의 따뜻함(R−B 평균) | 49.3 | 50.2 | 50.0 | 49 이상 |
| 어두운 점의 따뜻함 · 몫 | +8.6 · 6.0% | +6.8 · 4.7% | +6.7 · 4.5% | 0 이상 · 7% 이하 |
| 땅의 대비 큰 외톨이 점 · 체크무늬(천 개당) | 7.65 · 1.92 | 0.09 · 0.08 | 0.10 · 0.08 | 1 · 0.5 이하 |
| 풀의 큰 결(밝기 · 색조) | 5.57 · 3.68 | 5.72 · 4.32 | 5.79 · 4.20 | 5.6 · 3.7 이상 |
| 흙의 큰 결(밝기 · 색조) | 5.43 · 4.43 | 5.75 · 4.55 | 6.32 · 3.50 | 5.4 · 3.3 이상 |
| 흙·풀의 얼룩덜룩함 | 3.46 · 3.70 | 4.10 · 4.08 | 3.61 · 3.90 | 3.8 · 4.0 이하 |
| 얼룩이 어둡게 만든 점(대문·초가·담) | — | 8.8 · 15.3 · 9.5% | 2.9 · 6.0 · 1.9% | 5% · 8% · 5% 이하 |
| 사람 바깥과 바닥의 밝기 차 | 0.40~0.43 | (나) 0.31~0.37 | 0.32~0.40 | 0.3 이상 |
| 화면의 빛깔 수 | 68 | 59 | 60 | 96 이하 |

- 따뜻함은 장면 전체를 점 세 개마다 하나씩 잰다(`lib.mjs`의 `warmth`). "대비 큰" 외톨이 점·체크무늬는 이웃과 밝기 차가 큰 것만 센다 — 이웃 단계의 고운 결(수채화 같은 알갱이)은 세지 않는다.
- 얼룩덜룩함(`blotch`)은 맵 점 8×8 조각과 이웃 조각의 평균 밝기 차다. 큰 결(`monotony`)은 화면 전체의 퍼짐이다. 3.1차는 큰 결을 지금 이상으로 두고 이웃 조각끼리의 차만 지금 수준으로 낮췄다 — 얼룩이 크고 부드럽게 번진다.
- 흙의 큰 결 색조(3.50)는 지금(4.43)에 못 미친다. 지금과 3차의 흙 색조 퍼짐에는 잿빛 얼룩의 몫이 있는데, 4차에서 잿빛을 따뜻한 흙빛으로 옮겼으므로 그만큼 내려갔다(기준을 3.3으로 낮춘 까닭 — 기획서 4.7.5의 ㅌ).

## 아직 아쉬운 것

- 흙의 색조 퍼짐이 지금보다 작다(위). 흙길이 지금보다 조금 한결같아 보일 수 있다.
- "둘레보다 짙은 점"(`grime`의 `grimePct`)은 기둥·문살·처마 그늘처럼 꼴이 짙은 곳도 함께 세어, 3.1차에서도 거의 줄지 않는다(대문 26.6 → 27.0, 초가 22.8 → 20.1, 담 33.7 → 34.2). 때를 줄인 것은 "얼룩이 어둡게 만든 점"으로 잰다.
- 대문 기둥과 문짝의 나뭇결, 우물 돌에는 얼룩이 조금 남아 있다.
- 한 장뿐이다: 움직임, 옆·뒷모습, 다른 계절, 아침·해거름 빛이 없다. 들판(논·밭·물)·냇가·개·소는 그리지 않았다.
- 실제 태블릿에서 보지 않았다. PNG를 아이패드의 기기 화소로 찍었을 뿐이다.

## 참고 그림에 대해

사용자가 보여 준 참고 그림(남의 광고 그림)은 이 폴더에도 저장소에도 넣지 않았고, 따라 그리지 않았다. 그 그림의 들쭉날쭉한 점 크기와 빛 번짐, 중국·일본풍의 꼴(석사자, 깃발, 등불 기둥, 마법진)은 쓰지 않았다.

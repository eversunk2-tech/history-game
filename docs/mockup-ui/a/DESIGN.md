- 성공·위험 색은 따로 두지 않는다(점수·맞음·틀림이 없는 게임). 잠김은 **점선 + 자물쇠 + 흐린 글**, 꼭 할 일/덤은 **채운 네모/빈 네모 + 글**, 해는 **찬 해/빈 동그라미 + 숫자**로 — 색만으로 뜻을 전하지 않는다.

## 글꼴과 크기 단계

- 제목: **Hahmlet** 800(자간 −0.035~−0.045em) — 제목, 계절 이름, 숫자(수치·쪽 번호), 도장 글자.
- 이야기: **Gowun Batang** 400/700(줄 간격 1.5~1.78) — 대사, 소개, 계절 글, 할 일 이름, 선택지, 고른 것, 생긴 일.
- 정보·단추: **Gothic A1** 500/700/800 — 단추, 이름표, 캡션, 자판 표시. (게임에 넣을 때는 지금의 Pretendard로 갈음해도 된다 — 아래 참고)
- 한 화면에 셋까지. 본문(이야기 글)은 어린이용이라 붓글씨·장식 글꼴을 쓰지 않는다.

## 간격과 모양

- 간격: 0.25rem 단위(1024에서 4px). 화면 가장자리 1rem(맵·대화) / 2.25rem(제목·돌아보기 지면).
- 누르는 것: 모두 `max(56px, 3.5rem)` 이상(선택지 64px, 판권·작은 단추도 56px).
- 모서리: 단추·선택지 6px, 종이(쪽지·지면) 2px, 도장 3px. 동그라미는 쪽 번호·선택지 번호만.
- 테: 이중선(굵은 2px + 가는 1px)으로 머리·글줄·그림 아래를 마감, 칸 사이는 1px 먹선(22%), 목차 이음은 점선.
- 단추 셋: 주홍 단추(주 동작 한 화면에 하나) · 종이 단추 · 밑줄 글 단추(조용한 것). 잠김은 점선 + 자물쇠.

## 빛과 층

- 광원: **위(조금 왼쪽 위)** 하나 — 제목 그림의 해도 왼쪽 위.
- 바탕에 위에서 내리는 따뜻한 빛(타원 빛 한 겹) + 아래쪽 아주 옅은 그늘 + 한지 질감(옅게, multiply).
- 그림자 두 겹: `--shadow-1`(캡션·이름표) / `--shadow-2`(쪽지·단추·선택지) / `--shadow-3`(지면·두루마리). 짧고 진한 것 + 넓고 연한 것.
- 층 셋: 바탕(한지·맵·장면) / 떠 있는 종이(머리·쪽지·액자·두루마리·지면) / 잠깐 뜨는 것(고르기 판·도장).
- 윗면 1px 하이라이트(`--rim`)는 종이 단추·선택지에.
- 흐르는 빛: **금박 선 한 곳**에 9초에 한 번(제목 아래 금박 선, 돌아보기 제목 아래 금박 선, 고르기의 초점 선택지 아래 금박 선). 맵·대화(말하는 때)에는 흐르는 빛이 없다.
- 선택된 것이 가장 밝다: 화살표가 가리키는 쪽지 줄, 초점이 간 선택지.

## 그림 체계

- 대화 장면: 지금의 반실사 채색화(배경 23·인물 15) 그대로. 말하지 않는 사람은 밝기 80%.
- 맵: 3.1차 도트 그대로 — 늘이거나 줄이지 않는다(1180×690, 오른쪽 아래에 붙인다).
- 새로 그린 장식(SVG, 가는 먹선 1.5~2.6px, 낮은 채도): 도장(먹 번진 가장자리 — 바탕에만 걸고 글자는 또렷하게), 두루마리 나무 축, 접은 귀, 계절 삽화 넷(매화 가지·연못·감나무와 기와 담·눈 덮인 소나무 — 돌아보기에 한 벌).
- 그림에는 번호와 설명: “그림 1 · 1395년 봄, 느티골 어귀의 이른 아침 · AI(제미나이)로 만든 그림”, “그림 2 매화 가지” …

## 움직임

- 빠름 120ms: 단추 누름(2px 내려앉음, 그림자 줄어듦).
- 보통 240ms: 말하지 않는 사람이 어두워짐.
- 강조 400ms: 고르기 때 선 사람이 양옆으로 비켜섬.
- 금박 빛: 9초에 한 번 1.4초 동안 지나감. 두루마리 귀퉁이의 ▼: 1.6초에 3px 까딱임.
- 움직임 줄이기: 금박 빛·까딱임·비켜섬을 멈추고 정지된 하이라이트만 남긴다(점검함).
- 소리 없음.

## 하지 않을 것

- 의미 없는 그라데이션·빛나는 구슬, 이모지 아이콘, 같은 상자 반복, 왼쪽 색 띠 카드, 모두 가운데 정렬.
- 전통 문양을 화면 가득 깔기(한지 질감은 문양이 아니라 종이결, 옅게).
- 화풍 섞기: 맵은 도트, 장면은 채색화, 장식은 가는 먹선 — 서로 넘나들지 않는다.
- 금박을 글자나 넓은 면에 쓰기, 주홍을 넓은 면에 쓰기(주 단추 하나 + 점·도장).
- 이야기 글을 20px 아래로, 누르는 것을 56px 아래로.

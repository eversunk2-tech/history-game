# DESIGN.md — 시안 C 「두루마리 장면」

## 한 문장

그림이 주인공이고 UI는 한지 띠처럼 얇게 — 느티골에 들어가 있는 느낌.

## 스타일 (주 / 보조)

- **주: 에디토리얼·헤리티지** — 한지 띠, 먹 글자, 세리프 제목, 오방색은 점·선·작은 면에만(주홍 마름모·이름표·도장, 황 빛, 청 초점).
- **보조: 이머시브** — 화면 하나가 장면 하나. 장면 안에서 빛이 온다(제목의 해, 대화의 아침 빛, 고른 쪽지에 퍼지는 빛, 돌아보기에서 지금 계절에 모이는 빛).
- 가장 재밌다는 "동네 걷기"를 가리지 않게, 맵 위의 UI는 가장자리로 밀고 반투명 한지로 만든다.

## 글꼴과 크기 단계

- 제목 **Hahmlet** 600·700 / 이야기 글(대사·계절 글·고른 것) **고운바탕** 400·700 / 정보·단추·숫자 **Pretendard**(지금 게임의 것, `tabular-nums`). 한 화면에 셋까지.
- 크기는 게임과 같은 rem(1024×768에서 16px, 1180×820에서 17.08px):

| rem | 1024 / 1180 | 쓰임 |
|---|---|---|
| 1 | 16 / 17.1 | 이름표·띠의 작은 이름·쪽지 끝줄·단계 이름(딸림 글) |
| 1.125 | 18 / 19.2 | 띠의 단추, 쪽지 머리, 대화 이름 |
| 1.25 | 20 / 21.4 | **본문**(쪽지 줄, 두루마리 글), 단추 |
| 1.375 | 22 / 23.5 | 수치 숫자, 계절 글(자막), 제목의 소개, 주 단추 |
| 1.625~1.75 | 26~28 / 27.8~29.9 | 선택지 쪽지, 대사 |
| 2.375 | 38 / 40.6 | 돌아보기 제목 |
| 6.25 | 100 / 106.8 | 게임 제목(본문의 4.6배) |

- 제목 줄 간격 1.04, 자간 −0.04em. 본문 줄 간격 1.45~1.7, `word-break: keep-all`, 대사·자막은 `text-wrap: balance`. 따옴표 “ ”, 낫표 「 」는 게임 글 그대로.

## 간격과 모양

- 간격은 0.25rem(4px) 단위. 가장자리 여백 0.75rem(띠 아래 쪽지, 작은 지도), 제목·돌아보기의 왼쪽 정렬선 3.5~4.5rem.
- 모서리: 띠의 단추 0.5rem, 떠 있는 면 0.625~0.875rem, 주 단추 0.75rem, "나중에 할게요"는 알약, 선택지 쪽지는 손으로 자른 듯한 비대칭 모서리(6/11/7/10px)와 ±0.7° 기울기, 도장 0.2rem.
- 테두리: 1px 먹 16~22% 실선(머리카락 선). 잠긴 것은 1.5px **점선** + 자물쇠 + 흐린 글. 꼭 할 일은 **찬 마름모 ◆**, 덤은 **빈 동그라미 ○**(모양으로 가른다).
- 누르는 자리는 모두 3.5rem(56px) 이상. 잠긴 "봄을 보낸다"는 테만 2.875rem이고 누르는 자리는 위아래로 넓혀 3.6rem.

## 빛과 층

- 광원은 하나: 왼쪽 위(제목은 그림 속 해 — 왼쪽 산 너머). 그림자는 아래로.
- 그림자 두 겹: `--shadow-2` = 0 1px 2px(짧고 진함) + 0 14px 32px −10px(넓고 연함), `--shadow-3` = 0 2px 4px + 0 36px 72px −26px. 윗면 1px 하이라이트 `--rim`(먹 띠는 8%).
- 층 셋: ① 바탕 — 그림·맵·벽 한지 / ② 떠 있는 것 — 위 띠·할 일 쪽지·작은 지도·두루마리(`--shadow-2`) / ③ 잠깐 뜨는 것 — 수치 펼침·선택지 쪽지·계절 자막(`--shadow-3` 또는 안개).
- 흐르는 빛은 화면마다 1~2곳, 글 위로는 지나가지 않는다:
  - 제목: 주 단추 **테두리를 따라 도는** 가는 금빛(9초에 한 바퀴) + 해의 무리(7초 숨).
  - 대화(선택지): 누른 쪽지 둘레로 장면에 번지는 빛(3.4초 숨).
  - 돌아보기: 지금 계절의 그림에 모인 빛(6초 숨) + 그 칸 위의 금빛 선.
  - 움직임 줄이기면 모두 멈추고 정지된 빛만 남는다(`prefers-reduced-motion`).
- 선택된 것이 가장 밝다: 화살표가 가리키는 쪽지 줄, 누른 선택지, 지금 계절.

- 대화·돌아보기: 지금 게임의 **반실사 채색화**(`src/assets/pictures/**`) 그대로. 맵: 지금의 **도트**(3.1차) 그대로 — 시안에서는 `now/map-clean.jpg`(1180×690)를 창 가득 늘려(×1.19, 칸 그대로 `pixelated`) 깔았다. 게임에서는 캔버스가 창 가득 커지고 같은 크기의 칸이 더 보인다.
- 새로 그린 것은 CSS뿐(장식 SVG 없음): 두루마리 나무 축, 그림 위 제첨(세로쓰기 이름 쪽지), 주홍 도장 "한 해 살기", 선택지 쪽지. 화면마다 1~2개.
- 작은 그림 표시(곡식 자루·기운 찬 사람·맞잡은 손·해·자물쇠)는 게임의 `src/ui/icons.tsx` 그대로.

## 움직임

- 빠름 120ms(누름 — 아래 그림자가 줄며 3px 내려앉음) / 보통 240ms(쪽지 펴기, 수치 펼침) / 강조 400ms(선 사람이 비켜서기, 고른 쪽지가 떠오르기).
- 숨 쉬는 빛: 해의 무리 7초, 지금 계절 6초, 고른 쪽지 3.4초, "▶" 1.8초. 깜빡임 없음.
- 게임에 넣을 때 더할 것: 돌아보기를 열면 두루마리가 왼쪽 축에서 오른쪽으로 펼쳐지고(1.2초) 빛이 봄 → 겨울로 한 번 지나간 뒤, 누른 계절에 머문다. 도장은 마지막에 한 번 찍힌다. 움직임 줄이기면 펼친 채로 뜬다.

## 하지 않을 것

- 의미 없는 그라데이션·빛나는 구슬, 이모지 아이콘, 왼쪽 색 띠 카드, 전통 문양 깔기, 모든 것 가운데 정렬(가운데는 자막과 선택지뿐).
- 글 위를 지나가는 빛, 한 화면에 흐르는 빛 셋 이상.
- 도트 맵이나 채색화를 바꾸거나 새 화풍 섞기(새 장식은 CSS로만).
- 정답·오답·잠김을 색만으로 보이기(점선·자물쇠·마름모/동그라미·글을 함께).
- 소리.

- **한 해 돌아보기** — 네 계절 그림을 이은 두루마리와 맺음 도장으로 "한 해를 다 살았다"는 보람이 생겼고, 지금 계절에 빛이 모인다. ⑤ 네 칸에 글이 많아 두루마리 아랫부분이 빽빽하다(계절 글이 더 길어지면 칸 안에서 넘겨 보아야 한다).

## 미심쩍은 것

- **쪽지 자리를 왼쪽 위 → 오른쪽 위로** 옮겼다("봄을 보낸다" 바로 밑 — 할 일을 다 하면 위 단추가 풀린다는 것이 한눈에 보이고, 수치 펼침과 겹치지 않는다). 지금 게임의 알림(`map-toast`)이 쪽지 "곁"에 뜨는 자리도 함께 옮겨야 한다.
- 수치의 **열 칸 막대**가 띠에서 빠지고(숫자만), 누르면 보인다. 아이들이 넉넉함을 칸으로 보던 것이 한 번 눌러야 보인다.
- 대화의 넘기는 법 한 줄을 "첫 몇 창만" 보이려면 본 횟수를 어딘가에 세어야 한다(저장 꼴이 바뀔 수 있음 — 세션 안에서만 세면 저장은 그대로).
- 돌아보기의 계절 그림은 역할마다 달라야 한다(농민 집 아이는 논·냇가·타작 마당·뒷산 절). 그 계절의 꼭 할 일 자리에서 고르는 규칙이 필요하다.
- 1024×768에서 띠의 수치 그림 표시는 자리가 모자라 숨긴다(이름과 숫자는 남는다).
- 한지 결 타일은 거울 이음이라 넓은 면(돌아보기 벽)에서 대칭이 아주 옅게 보일 수 있다(ASSETS.md에 적힌 대로 게임에 넣을 때 다듬는다).
- 시안은 글꼴을 Google Fonts·jsDelivr에서 부른다(인터넷이 필요). 게임에는 파일로 넣는다.

# DESIGN.md — 시안 B 「단청 그림책」

## 한 문장

“5학년이 손가락으로 누르고 싶어지는, 오방색 그림책 같은 느티골.”
한지 위에 먹 글자로 차분하게 읽히되, 누르는 것은 모두 말랑한 점토처럼 손에 잡힐 듯하게. 맵의 도트를 UI 아이콘에도 써서 화면 전체가 한 판처럼 보이게 한다.

## 스타일

- 주: 에디토리얼·헤리티지 — 한지 바탕, 먹 글자, 단청 띠(선), 번호 붙은 견본(그림 1~5), 정보는 표처럼 정돈.
- 보조: 산뜻·친근 — 점토 단추(윗면 흰 빛 + 아래 5px 그림자, 누르면 내려앉음), 파인 트랙 안의 젤리 막대, 칭찬 한 줄, 손가락 안내.
- 어린이 느낌의 선: 캐릭터 마스코트·이모지·느낌표 남발 없음. 둥근 제목체는 제목·단추에만, 이야기 글은 바탕체.

## 간격과 모양

- 4px 단위(0.25rem). 화면 둘레 1–1.75rem, 패널 안 0.75–1.5rem.
- 모서리: 패널·카드 1.5rem(24px), 말풍선 2rem, 단추 1rem(큰 단추 1.25rem), 칩·쟁반은 완전히 둥글게, 체크 칸 0.625rem.
- 테두리는 거의 쓰지 않는다(그림자와 윗빛으로 층을 가른다). 점선 테는 “잠김”과 “아직 아닌 단계”에만.
- 누르는 것은 모두 3.5rem(56px) 넘게. 판 번호처럼 작아 보이는 것도 누를 자리는 56px.

## 빛과 층

- 광원 하나: 왼쪽 위(제목 그림에서 해가 뜨는 쪽). 그래서 그림자는 아래로, 조금 오른쪽(1–2px)으로 기운다.
- 층 셋: 바탕(한지·그림) / 떠 있는 패널(`--sh-2`: 짧고 진한 1px + 넓고 연한 0.75rem/1.75rem) / 잠깐 뜨는 것(계절 글·말풍선·돌아보기 종이, `--sh-3`).
- 윗면 하이라이트 `inset 0 2px 0 rgba(255,255,255,.8)`를 모든 점토 면에.
- 점토 단추: 아래 5px 단단한 그림자(같은 색의 진한 테) + 넓은 확산 그림자. 누르면 5px 내려앉고 단단한 그림자가 사라진다(120ms). 잠긴 단추는 처음부터 내려앉아 파인 자리.
- 파인 트랙: 탭 묶음, 젤리 막대, 덤 미션 쟁반 — 안쪽 그림자(위가 어둡다).
- 흐르는 빛: 주 단추 하나에만 7.5초에 한 번 지나간다(제목의 “이어 하기”, 돌아보기의 “다음”). 글자 위를 지나도 38% 폭·40% 흰빛이라 읽기를 막지 않는다. 움직임 줄이기면 없다.

## 그림 체계

- 대화·돌아보기: 지금의 반실사 채색화(`src/assets/pictures/**`) 그대로. 돌아보기에는 계절마다 그 계절의 배경 한 조각(봄 논, 여름 논, 가을 타작 마당, 겨울 절)을 띠로 잘라 쓴다.
- 맵: 지금의 3.1차 도트 그대로(`map-clean.jpg`를 늘이지 않고 위에 붙였다).
- **새 도트 아이콘(16×16)** — `px.js`: 곡식 자루·두 팔 든 사람·맞잡은 손(수치 셋), 해·진 해, 자물쇠, 두루마리(지난 이야기), 쪽빛 보자기(봇짐), 초가(처음으로), 손가락, 계절 넷(새싹·볏잎·벼 이삭·눈송이), 생활 카드. 면만 칠하고 먹 테 한 칸을 저절로 두른다. 늘 정수 배(32·40·24px)로 그린다. 게임의 도트와 같은 먹 테·낮은 채도라 맵과 UI가 이어진다.
- **새 장식(화면마다 1~2개)**: 단청 띠(먹 2·흰 1·뇌록 3·흰 1·주홍 2px — 위 띠 아래, 제목 아래 짧게, 돌아보기 머리 아래), 이름 리본(제비꼬리, 먹 테·황 선·뇌록 몸), 계절 도장(세 겹 테 + 거친 가장자리 필터), 칭찬 줄 밑의 황 붓줄(손 흔적 — 화면에 하나).

## 움직임

- 빠름 120ms: 단추 누름·떠오름(올리면 1px).
- 보통 240ms: (게임에 넣을 때) 선택지가 뜰 때 두 사람이 비켜서기 — 지금 게임의 0.22s를 그대로.
- 강조 400ms 넘게: 주 단추의 반짝 빛(0.97s 지나가고 7.5초마다), 손가락 끝의 물결(2.4초), “다음 ▼”의 까딱임(1.4초).
- `prefers-reduced-motion: reduce`이면 셋 다 멈추고 정지된 하이라이트만 남는다.

## 하지 않을 것

- 이모지 아이콘, 마스코트 캐릭터, 빛나는 구슬·보라 그라데이션.
- 전통 문양을 바탕 가득 깔기(단청은 띠·리본·도장의 선과 작은 면으로만).
- 대화 장면에서 띠를 검게 바꾸기(맵과 같은 한지 띠의 위 줄만 남긴다).
- 주홍을 두 곳 넘게(한 화면의 주 단추 하나 + 꼭 할 일 표시).
- 밝은 색 위 흰 글자, 색만으로 상태 알리기, 56px보다 작은 누를 자리.
- 맵 도트를 늘이거나 새 화풍의 그림을 섞기.

## 주 단추 색 후보(B를 고른 뒤 — 빨강 대신)

사용자가 B를 고르고 “주 단추를 빨간색 말고 더 어울리는 색으로” 하자고 했다. 주홍(`#c4462a`)이 맡던 자리 — “이어 하기”·“다음 ▶”·풀린 “봄을 보낸다 ▶”·고른 선택 카드의 점, 그 단추의 윗빛·아래 테·그림자·누름 — 를 아래 후보로 바꿔 끼운다. 주홍은 “꼭 할 일”의 작은 표시(네모·체크 칸·책갈피 윗줄)에만 남는다.

### 바꿔 끼우는 법

- 토큰 한 묶음(`b.css`의 `:root`): `--btn`(단추 몸) · `--btn-edge`(아래 테) · `--btn-on`(단추 위 글자) · `--btn-hi`(윗면 빛) · `--btn-glow`(넓은 그림자 빛깔) · `--btn-soft`/`--btn-soft-edge`(대화의 “다음 ▼” 같은 옅은 짝) · `--focus`(초점 테) · `--jelly`(젤리 막대).
- 후보는 `[data-btn='1'|'2'|'3']` 묶음. 주소 끝에 `?btn=1`을 붙이면(`btn.js`) 그 후보로 보인다: `index.html?btn=1`, `1-title.html?btn=2` …. 아무것도 없으면 처음 시안(주홍) 그대로.
- 견줌: `colors/compare-buttons.jpg`(`colors/compare.html`을 찍은 것 — 처음 주홍 + 후보 셋, 같은 부품). 후보마다 네 화면: `colors/1-jjok/sheet.jpg`, `colors/2-songhwa/sheet.jpg`, `colors/3-meok/sheet.jpg`.
- 맵·대화의 기본 상태에는 주 단추가 없다(“봄을 보낸다”는 잠김). 그래서 두 화면은 후보마다 “다음 ▼”의 옅은 빛깔과 젤리 막대만 다르다. 풀린 “봄을 보낸다 ▶”는 견줌 한 장에 있다.

### 권하는 것: 1 쪽빛

한지·채색화·도트가 모두 따뜻한 빛깔이라, 찬 쪽빛 하나만 단추에 쓰면 제목·돌아보기·고르기 어디서나 “누를 곳”이 가장 먼저 보이고, 꼭 할 일(주홍)·해와 막대(황)·계절 색 어느 것과도 뜻이 겹치지 않는다. 바꿀 것은 토큰 묶음과 초점 테 하나뿐이다. 다음은 2 송화 — 더 친근하지만 노랑이 이미 해·막대·길잡이에 많아 막대 색까지 바꿔야 한다.

# 시안 A 「펼친 이야기책」 (권함)

## 한 문장

**이야기책을 정말 펼친 책으로** — 왼쪽 면은 일곱 이야기의 목차, 오른쪽 면은 지금 살 이야기의 그림 표지와 쪽빛 단추 하나.

- 스타일: 주 에디토리얼·헤리티지(목차의 점줄과 번호, 두 주제의 갈피, 이중선 머리글, 그림 액자와 낙관 같은 도장, 종이가 떠 있는 그림자) / 보조 산뜻·친근(점토 단추, 누르면 내려앉음).
- 시안 B 「단청 그림책」·쪽빛 단추(㉠)의 토큰·단추·글꼴을 그대로 쓴다 — 시안은 게임의 `src/styles/base.css`·`fonts.css`를 그대로 불러 쓴다(글꼴도 게임의 파일).

## 무엇이 고급스러워졌나

1. **같은 상자 일곱 → 책 한 권.** 화면 이름이 "이야기책"이라, 펼친 책의 꼴이 바로 읽힌다. 가운데가 접혀 그늘지고, 바깥 가장자리에 종이가 겹친 결, 위에서 뇌록 갈피끈이 늘어진다.
2. **주인공이 하나.** 오른쪽 면의 표지(채색화 + 큰 해 + 제목 + 쪽빛 단추)가 이 화면의 주인공이고, 목차는 받쳐 준다.
3. **누를 곳이 한눈에.** 쪽빛 면은 표지의 단추 하나(목차에서는 그 줄의 번호만 쪽빛). 다른 열린 줄은 쪽빛 글 "다시 살기 ▶".
4. **그림.** ①의 표지는 지금 게임의 채색화(마을 어귀 봄 — 느티나무)를 다시 쓴다. 새 그림 없음.
5. **도장이 낙관처럼.** 붉은 인주 도장 → 뇌록 도장(세 겹 테, 거친 가장자리)이 그림 오른쪽 아래에 찍힌다(spec 1.2의 "도장은 뇌록").
6. **교과서의 두 주제가 목차의 갈피.** 안내 줄의 말 그대로("건국부터 병자호란까지" ①~④ / "조선 후기부터 개항 이후까지" ⑤~⑦). 새 낱말 없음.

## 상태(시안의 `?s=`)

- `ga` (가) 처음 — ①만 열림. 오른쪽 면 = ① "펼치기 ▶".
- `na` (나) ①을 한 번 깸 — 오른쪽 면 = ①, 그림에 도장 "글자를 익힌 한 해", "깬 이야기 · 한 번 살았어요", "살아 본 모습: 여자아이 모습", "다시 살기 ▶". 도장이 한 번 찍힌다(방금 깬 때).
- `da` (다) 앞날 — ①② 열림, ①은 두 번 깸. 오른쪽 면 = ②(아직 깨지 않은 열린 이야기 가운데 가장 앞). ①은 목차 줄에 작은 도장 + 깬 횟수 + 살아 본 모습 + "다시 살기 ▶". **②의 그림은 아직 없어 시안에서는 ①의 향교 그림으로 자리만 잡았다(그림 위에 "시안:" 딱지).**
- `parts` (라) 부품 — 목차 줄의 기본·누름·초점·잠김·펼친 줄·깬 줄, 표지 단추의 기본·누름·초점, 도장과 찍히는 첫 장면, 먹 밑그림(시안 B·C용 — A의 화면에는 나오지 않는다).

## 그림이 필요한가

**아니다.** ①은 지금 그림(`src/assets/pictures/bg/s1395/entrance-spring.jpg`)을 다시 쓴다. ②부터는 그 이야기를 만들 때 생기는 그 이야기의 마을 어귀 그림을 쓴다(spec 12.4). A에서 준비 중인 이야기는 목차의 한 줄이라 그림 자리가 없다.

## 시안 파일

`index.html`·`a.css`·`a.js`(이 시안), `../common/`(세 시안이 함께 쓰는 자료·먹 밑그림·도장), `shots/`(상태 넷 × 1024×768@2·1180×820@2, (나)의 1366×650@1·1920×1080@1), `sheet.jpg`. 보는 법: 저장소 맨 위에서 정적 서버를 띄우고 `docs/mockup-ui/book/a/index.html?s=na`(오른쪽 아래 가·나·다·라로 상태를 바꾼다). Pretendard는 게임처럼 `node_modules`의 파일을 부른다.

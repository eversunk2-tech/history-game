# 시안 C 「연표 두루마리」

## 한 문장

**두루마리 위 연표에 일곱 해가 놓인다** — 금빛 시간 줄의 점까지 먹줄이 내려가 해와 해의 거리가 보이고, 일곱 이야기의 소개 글이 모두 보인다(옆으로 넘겨 본다).

- 스타일: 주 에디토리얼·헤리티지(두루마리 축, 금박 선, 100년 눈금, 교과서 두 주제의 띠, 먹 밑그림) / 보조 산뜻·친근(점토 카드, 누르면 내려앉음). 3판 기획서 4절의 "일곱 이야기가 두루마리에 연대순으로"를 그대로 그렸다.

## 무엇이 고급스러워졌나

1. 일곱 해가 **시간 줄** 위에 놓인다: 1395·1446은 가깝고, 1446과 1592 사이는 멀다 — 카드에서 내려오는 먹줄이 기울어 시간의 거리가 보인다(역사 공부의 맛).
2. 교과서의 두 주제가 시간 줄 아래의 띠로 깔린다(안내 줄의 말 그대로).
3. 두루마리 축(왼쪽 면이 밝은 나무)과 축으로 말려 들어가는 종이 그늘 — 광원 하나.
4. **모든 소개 글이 보인다**(시안 A·B는 준비 중의 소개 글이 목차·접힌 폭에서 빠진다).

## 아쉬운 점(고르지 않은 까닭)

- 일곱 장이 한 화면에 들지 않는다 — 1024 너비에서 3장 반, TV에서 5장쯤. **옆으로 넘겨야** 하고, 그것을 알리는 **새 말 둘**이 필요하다: "옆에 더 있어요 ▶" · "◀ 앞에 더 있어요"(게임의 "아래에 더 있어요 ▼"의 짝). 마우스 휠을 옆 넘김으로 바꾸는 코드도 든다.
- 일곱 카드가 같은 크기라 지금 살 이야기가 덜 두드러진다(가장 밝고 쪽빛 단추가 있지만).
- 그림 체계에 먹 밑그림이 하나 더 들어온다.

## 쓴 토큰과 새 토큰

- 게임 `base.css`의 토큰·부품 그대로.
- 새것: 두루마리 축 `#3a2c20`→`#8a6a4b`→`#2f251c`(나무, 왼쪽이 밝다), 금박 선 = `--hwang` 3px + 먹 1px, 해의 점(열림 먹 · 지금 살 이야기 쪽빛 · 준비 중 빈 동그라미 + 점선 먹줄), 주제 띠 = `--paper-deep` 파인 쟁반 + `--ink-soft` 글(7.8:1).

## 확인(머리 없는 크롬)

- 상태 넷 × 1024×768@2·1180×820@2, (나)의 1366×650@1·1920×1080@1: 글 잘림·18px 아래 글·56px 아래 누름 0. 두루마리 칸만 옆으로 넘친다(뜻한 것 — 1024에서 1736px 가운데 932px이 보인다).

## 그림이 필요한가

새로 받을 그림은 없다(①은 지금 채색화, 준비 중은 코드로 그린 먹 밑그림). 준비 중 카드에도 채색 표지를 원하면 spec 12.4의 제미나이 계획표.

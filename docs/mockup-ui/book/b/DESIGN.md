# 시안 B 「일곱 폭 병풍」

## 한 문장

**일곱 이야기가 한 벌의 병풍으로 이어 선다** — 지금 살 이야기 한 폭만 활짝 펴져 채색화와 소개 글을 보이고, 나머지 여섯 폭은 접힌 좁은 폭에 세로쓰기 제목.

- 스타일: 주 에디토리얼·헤리티지(병풍의 비단 회장, 세로쓰기 제목 띠, 먹 밑그림) / 보조 산뜻·친근(점토 단추, 누르면 내려앉음). 토큰·단추·글꼴은 게임의 `base.css`·`fonts.css` 그대로.

## 무엇이 고급스러워졌나

1. 화면 가득 한 벌의 병풍 — 일곱 이야기가 "한 작품"처럼 이어진다. 교실 TV에서 가장 장관이다.
2. 접힌 꼴의 빛: 병풍이 지그재그로 서 있어 홀수 폭은 왼쪽 위의 빛을 받고 짝수 폭은 살짝 그늘진다(광원 하나).
3. 준비 중인 폭은 **먹 밑그림**(아직 채색하지 않은 그림 = 준비 중)과 세로쓰기 제목. 열린 폭은 밝은 종이.
4. 활짝 편 폭에 ①의 채색화와 뇌록 도장, 쪽빛 단추 하나.

## 아쉬운 점(고르지 않은 까닭)

- 세로쓰기 제목은 5학년이 읽기에 느리고, 쉼표가 어색하게 놓인다("새 나라、새 도읍").
- 접힌 폭에는 소개 글과 "살아 본 모습: …"이 들어가지 않는다(읽는 글로만). 깬 이야기의 세로 도장은 알아보기 어렵다.
- 열린 이야기가 늘어날수록(②~⑦) 접힌 폭 안에 넣을 것(도장·깬 횟수·"다시 살기 ▶")이 많아져 좁은 폭이 빽빽해진다.
- 그림 체계에 먹 밑그림이 하나 더 들어온다.

## 쓴 토큰과 새 토큰

- 게임 `base.css`의 토큰·부품 그대로(시안 A와 같음).
- 새것: 비단 회장 `#4a3a2c`(위 `#5a4836` → 아래 `#3c2f24`) — 글이 올라가지 않는다. 바닥 그림자 `rgba(40,24,10,.4)`. 접힌 폭의 빛 `rgba(255,252,244,.35)`·그늘 `rgba(58,38,18,.12)`(꾸밈).
- 세로 도장: 시안 A의 뇌록 도장을 `writing-mode: vertical-rl`로.

## 확인(머리 없는 크롬)

- 상태 넷 × 1024×768@2·1180×820@2, (나)의 1366×650@1·1920×1080@1: 글 잘림·가로 넘침·18px 아래 글·56px 아래 누름 0. 넘겨 보는 칸 없음(모두 한 화면).

## 그림이 필요한가

새로 받을 그림은 없다(①은 지금 채색화, 준비 중은 코드로 그린 먹 밑그림 `../common/art.js` — 약 6KB). 준비 중인 폭에도 채색 표지를 원하면 spec 12.4의 제미나이 계획표(②~⑦, 여섯 장).

# 은행의 근거 — 4-1 ㉮(서당 2-1 · 2-2)

4-1 ㉮(은행 Build)가 쓴 기록이다. 새 근거(`src/content/bank/sources.ts`의 `bankSources`)마다 출처 쪽을 직접 열어 읽었고, 연 날은 모두 **2026-11-10**이다. 확인한 구절은 요지만 적는다(길게 옮기지 않는다). 조정자가 승인 뒤 spec 12.2에 옮긴다.

- 주소의 꼴: 백과 = 한국민족문화대백과사전 `https://encykorea.aks.ac.kr/Article/E…`, 우리역사넷 = `https://contents.history.go.kr/mobile/…/view.do?levelId=…`, 실록 = `https://sillok.history.go.kr/id/…`.
- 문제 번호는 `soc5-` 를 뺀 꼴(`2-1-0005` = `soc5-2-1-0005`)로 적는다.
- 지도서·교과서는 사용자의 지도서 PDF(5-2 사회 2단원, 겹침 검사에는 1·3단원도)를 썼다. 근거는 `E9`와 차시로만 적고 글·그림·평가 문항을 옮기지 않았다.

## 1. 번호를 고른 법 — 꼭 읽을 것

- **12.2의 F05·F07·F16·F30·F33·F53·F68·F85** — 처음 바퀴에는 `content/sources.ts`(3판 묶음)에 이 여덟 줄이 없어 검사기가 "근거 목록에 없는 번호"로 잡았다. 그래서 같은 사실을 출처 쪽을 다시 열어 새 번호로 적었다(F05→F107, F07→F115, F16→F104, F30→F114, F33→F116, F53→F121, F68→F122, F85→F101). **고침 바퀴(2026-11-10, ㉯ 8절 — 조정자 결정)**: ㉢이 여덟 줄을 `content/sources.ts`로 옮겼다. ① **F53·F68로 되돌렸다** — 2-2-0039·0058·0075의 F121을 F53으로, 2-2-0078의 F122를 F68로 바꾸고(0078의 물음·풀이는 F68의 사실 칸만큼으로 줄였다), `bankSources`에서 F121·F122 줄을 없앴다. ② 나머지 여섯은 새 줄이 원래 줄보다 넓어 **새 줄을 남기고**, 원래 사실 칸이 받쳐 주는 문제에 **원래 번호를 덧붙였다** — F05: 2-2-0001·0002·0003·0006·0010·0011·0015·0016·0017(0003은 "글 모르는 백성"의 까닭을 F05와 E9가 받쳐 F107을 뺐다), F07: 2-2-0052·0058, F16: 2-1-0076·0077, F30: 2-2-0058, F33: 2-2-0067, F85: 2-1-0061·0062·0076.
- **F98·F99는 비워 두었다.** `tests/bank.test.ts`(208줄)·`tests/content4.test.ts`(238·268줄)가 `'F99'`를, `tests/content.test.ts`(576줄)가 `'F98'`을 "목록에 없는 번호"의 견본으로 쓴다. 이 번호를 `bankSources`에 두면 그 시험이 깨진다(시험은 이 조각이 고칠 수 없다). 그래서 F86~F97 다음은 F100부터다. 고침 바퀴에서 없앤 F121·F122도 **비워 둔다** — 한 번 쓴 번호를 다른 뜻으로 다시 쓰지 않는다. 그래서 `bankSources`는 33줄(F86~F97, F100~F120)이고 빈 번호는 F98·F99·F121·F122다.

## 4. 엇갈리거나 흐려서 묻지 않은 것(12.3에 더할 만한 것)

1. **백운동 서원이 선 해** — 서원 항목은 1543년, 소수서원 항목은 1542년(사우는 1542년). → 해를 묻지 않고 "주세붕이 세운 서원의 시작"과 "1550년 첫 사액"만 물었다.
2. **『삼강행실도』의 인원과 해** — 항목마다 105명·110명, 편찬 1431·1432년, 반포 1434년 11월. → 반포한 1434년만 쓰고 인원은 묻지 않았다. 성종 때의 한글 언해본도 1481년(우리역사넷 kc_r300740)·1490년(백과 E0073192)으로 엇갈려, 고침 바퀴에 2-2-0009의 풀이에서 해를 뺐다.
3. **숙정문의 덕목** — 우리역사넷 교육 자료(eh_r0220)는 네 대문 이름이 인·의·예·지를 담았다고 하고, 지도서는 숙정문만은 덕목이 아니라 "정숙"을 바란 이름이라는 견해를 적는다. → 인(흥인지문)·의(돈의문)·예(숭례문)만 물었다. 보신각과 "신"도 묻지 않았다.
4. **성균관이 선 해** — 지도서 참고 자료는 1395년, 백과는 1395년에 공사를 시작해 1398년 창건. → 12.3 그대로 1395년을 쓰지 않고, 순서 문제(2-1-0076)의 풀이만 1398년(F101 — 12.2의 F85와 같은 사실)으로 적었다.
5. **근정전 앞 박석의 까닭**(눈부심·미끄럼을 줄이려고 거칠게 다듬었다) — 지도서만 "~라고 한다"로 적고 다른 출처를 찾지 못했다. → 묻지 않았다.
6. **『음식디미방』이 "가장 오래된 한글 조리서"인지** — 백과의 다른 항목(최씨음식법)이 더 앞선 한글 조리서를 든다. → "1670년쯤 딸과 며느리를 위해 쓴 음식 책"까지만 물었다.
7. **허난설헌의 시** — 위작이 섞였다는 옛 비판이 있다. → 여성 시인이라는 것과 허균을 거쳐 중국에서 책으로 나온 것만 물었다.
8. **혼인 나이** — 법(남 15·여 14세)과 실제 관행(양반가 17~19세쯤)이 다르다. → 법이 정한 나이만 물었다.
9. **1801년에 풀어 준 노비** — 백과는 "내시노비"(내수사·각사 노비) 6만 6천여 명. → "나라에 딸린 노비 6만여 명"으로 풀어 썼다.
10. 12.3의 16번(전기 양반의 군역)과 9번(노비가 향교에 다녔는지)은 묻지 않았다. 지도서가 양반은 "국역을 면제받았다"고 적는 대목도 쓰지 않았다.
11. **의녀**·**김만덕**은 여성의 지위 묶음에 넣을 만했으나 근거를 직접 다 읽지 못해(의녀는 검색 요약만) 넣지 않았다.

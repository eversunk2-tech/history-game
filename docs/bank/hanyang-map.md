# 한양 지도의 자리 표 (`spot.map = 'hanyang'`)

4-1 ㉮(은행 Build)가 정했다(2026-11-10). 서당 2-1 「조선의 건국과 한양」의 지도에서 찍기 여섯 문제(`soc5-2-1-0021`~`0026`)가 이 표의 자리를 쓴다. 지도 그림은 ㉣(서당)의 Build가 이 표대로 코드로 그린다(spec 9.8 — 새 꾸러미 없이 SVG).

## 이 표를 읽는 법

- **틀**: 가로 100 × 세로 100의 칸. 왼쪽 위가 (0, 0), **위가 북쪽**, x가 커질수록 동쪽, y가 커질수록 남쪽이다.
- **늘리는 법**: 틀이 가로세로 100의 정사각형이니, 화면에서는 가로세로를 같은 비율로 늘린다(찍는 둘레가 둥글게 남게). (고침 바퀴 — ㉯ 9절)
- **대강이다**: 정확한 축척이 아니다. 실제 자리의 위도·경도를 이 틀에 대강 옮기고(경도 126.955°~127.015°를 x 0~100으로, 위도 37.600°~37.548°를 y 0~100으로), 찍는 둘레가 겹치지 않게 조금씩 다듬었다. 맞추려 한 것은 **"어느 쪽에 있나"**(종묘는 경복궁의 동쪽, 사직단은 서쪽, 숭례문은 남쪽, 숙정문은 북쪽 …)다. 거리와 모양은 믿지 않는다.
- **찍기**: 문제의 `spot`은 `{ map: 'hanyang', x, y, r }`이고 답은 찍을 곳의 이름이다. 아이가 누른 점이 (x, y)에서 r 안이면 맞다.
- **방향의 말**: 문제는 동서남북으로만 묻는다("궁궐의 동쪽", "도성의 서쪽 대문"). "왼쪽·오른쪽"을 쓰지 않는다(spec 8.5). 지도에도 그 낱말을 쓰지 않는다.

- 산·청계천·숙정문은 지금 찍기 문제의 답이 아니다. 지도를 읽는 기준(북악산 아래의 궁궐)과 그림의 짜임으로 둔다. 뒤에 찍기 문제를 더하면 이 자리와 r을 그대로 쓴다.

## 선

- **도성(성곽의 대강)** — 이 차례로 이어 닫는다(네 산의 능선을 따라 빙 둘러 쌓았다 — F93): 창의문(19, 14) → 북악산(25, 13) → 숙정문(43, 8) → 혜화문(78, 24) → 낙산(87, 37) → 흥인지문(91, 54) → 광희문(90, 68) → 남산(56, 92) → 숭례문(34, 77) → 소의문(26, 71) → 돈의문(21, 61) → 인왕산(6, 28) → 창의문. 4소문(혜화문·광희문·소의문·창의문)은 선의 꺾이는 점으로만 쓰고 이름을 달지 않아도 된다(문제에 쓰지 않는다).
- **청계천** — 도성 가운데를 서쪽에서 동쪽으로(F95): (30, 60) → (50, 59) → (70, 59) → (88, 61) → (90, 63)에서 성 밖으로 나간다. 흥인지문의 찍는 둘레(91, 54, r 6)에 닿지 않게 남쪽으로 비껴 나간다. 찍을 곳으로 쓸 때의 가운데점은 (55, 59), r 5.

## 그릴 때(㉣에게 권하는 것 — 정하는 것은 ㉣의 Build)

- 찍을 곳(궁궐·제사 터·대문)에는 **이름을 쓰지 않는다** — 이름이 곧 답이다. 모양(지붕·문루·제단)만 그린다.
- 산과 청계천은 이름을 써도 된다(0021이 "북악산 아래"를 기준으로 묻는다).
- 북쪽을 가리키는 방위표("북")를 둔다. 아이가 동서를 지도에서 바로 읽게 한다.
- 지도는 조선 때의 모습이다(돈의문을 그린다).

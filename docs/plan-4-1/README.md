# 4-1 배치 시안(spec.md 11.1)

4판 첫 바퀴 4-1 "느티나무 마을에서 첫 출전"의 구현 계획에 붙인 **배치 그림**이다. 최종 그림이 아니다. 무엇이 어디에 있는지, 단추 크기(56px 이상), 글자 크기(본문 20px 이상)를 회색 상자로 보인다. 모두 1024×768(태블릿 가로, CSS 화소)이다.

| 파일 | 보이는 것 |
|---|---|
| `battle-hand.png` | 겨루기 화면 — 카드를 고르는 차례. 위: 고비의 이름·「옛이야기」 표시·단계·방패 칸·기운 막대. 오른쪽: **다음 차례에 고비가 할 일**(그림 표시 + 한 줄). 가운데: 고비 그림 자리. 왼쪽: 정령의 말풍선. 아래: 내 기운·기세 칸·"함께 하기"(합동 기술)·손패 넷(이번 판에 센 카드는 ★) |
| `battle-question.png` | 겨루기 화면 — 카드를 낸 뒤 뜨는 문제 창. 무대가 어두워지고 가운데에 문제 종이, 고를 것 넷(세로, 64px), 정령의 귀띔. 아래 두 상자는 답한 뒤의 두 모습(맞았어요 ○ / 아쉬워요 + 풀이 한 줄) |
| `hub-layout.png` | 느티나무 마을(거점) 맵의 배치도 — 48×36칸 전체를 줄여 그렸다. 가운데 시간의 문(큰 느티나무)과 알림판, 4-1에 여는 서당·도구점·포목점·댕기방, "곧 열려요" 여섯, 문 앞 칸, 주인공이 처음 서는 곳, 아이패드 한 화면의 넓이(점선), 위쪽 띠(레벨·경험치·돈 주머니·바로 가기 셋) |

- 그림 자리(도깨비·정령·카드의 도트)는 점선 상자와 글로만 적었다. 남의 게임 그림, 참고로 받은 광고 그림, 지도서·교과서의 그림을 쓰지 않았다.
- 문제 창의 물음과 고를 것은 spec 1절의 예("1395년 봄, 나라가 궁궐을 짓던 농민들을 집으로 돌려보낸 까닭은?")를 쓴 보기다. 실제 문제는 4-1의 Build가 근거와 함께 쓰고 Review가 검증한다(11.1의 라).
- 숫자(기운 52/90, 카드 힘 11 등)는 spec 8.1의 첫 어림을 옮긴 보기다.

## 다시 만드는 법


# 미연시 구도 시안 (2026-10-08)

사용자가 화풍을 승인한 시안이다("미연시 느낌 나며 마음에 든다"). 앞으로 만드는 대화 장면 그림은 이 두 장을 기준으로 같은 화풍에 맞춘다.

| 파일 | 내용 |
|---|---|
| `index.html` | 화면 시안(대화 장면, 선택 장면). 그림을 안에 담아 파일 하나로 열린다 |
| `template.html` | 위 시안의 원본(그림을 파일로 가리킨다). 고칠 때는 이것을 고치고 그림을 다시 담는다 |
| `bg-village-spring.jpg` | 배경 시안 원본, 1920×1080. 1395년 봄 느티골 마을 어귀 |
| `char-farmer-child.png` | 인물 시안 원본, 1024×1536, 투명 바탕. 농민 집 아이(열다섯 살) |

## 만든 방법

도구는 연결된 캔바(Canva)의 그림 생성이다. 그림은 캔바 계정의 업로드에 남아 있다.

| 그림 | 캔바 그림 아이디 | 비율 |
|---|---|---|
| 배경 | `MAHXV-jRVog` | 16:9 (원본 1680×944) |
| 인물(회색 바탕) | `MAHXV1WRn28` | 2:3 (원본 1024×1536) |
| 인물(바탕 지움) | `MAHXV3qxdX0` | 위 그림에서 바탕 제거 |

원본 크기 파일로 받는 길(그림 생성 결과는 작은 미리 보기만 돌려준다):

1. 그림을 생성한다. 인물은 이어서 바탕을 지운다.
2. 캔바 디자인 「조선에서 한 해 살기 - 화면 시안」(`DAHXV3KUSA4`)에 쪽을 더하고 그림을 쪽 크기에 맞게 올린 뒤 저장한다. 배경 쪽은 1920×1080, 인물 쪽은 1024×1536.
3. 그 쪽을 내보낸다. 배경은 JPG, 인물은 "투명 바탕" PNG.
4. 받은 파일을 줄여서 넣는다. 시안에서는 배경 1600×900 JPEG(품질 82) 약 250KB, 인물 WebP(높이 1200) 약 75KB였다.

A dirt path leads from the foreground into the village. On both sides are plowed fields and paddies being prepared for sowing (bare wet soil, no neat rows of transplanted seedlings). Gentle forested mountains in the distance, blue sky with soft white clouds.

## 알아 둘 것

- 옷(저고리 길이, 고름), 땋은 머리, 돌담과 초가, 꽃나무는 **고증을 확인한 것이 아니다.** 생성 그림은 장마다 사람이 보고 시대에 맞지 않는 것을 걸러야 한다.
- 배경은 회화풍, 인물은 애니메이션풍으로 결이 조금 다르다. 사용자는 이대로 좋다고 했다.
- 같은 인물을 표정만 바꿔 다시 만들 때, 새 인물을 같은 화풍으로 만들 때는 위 그림을 참고 그림으로 함께 넣어 생김새와 화풍을 맞춘다.
- 시안 속 문장과 수치는 구도를 보이기 위한 예시다.
